# 《文舟 0.9.9》宣传片故事板

改编自《炉火祈愿》第一部 · 根据宣传片大纲编制

我建议将这支宣传片制作成一部以《炉火祈愿》为叙事主体、以文舟功能操作为画面组成部分的二维动画短片。

故事不应为了展示软件功能而中断。词条、人物关系、地图和大纲应当像是在小说世界上叠加了一层创作界面，让观众一边观看里加的故事，一边看到这个世界如何被文舟记录下来。

建议时长 2分49秒 · 16:9 横屏 · 19个分镜

画面：代码绘制的侧透视、低多边形、大色块平涂风格。对白以小说原文为主，按配音需要删节，不改动人物的语言风格。

## 一、视觉基调

参考所附封面的造型方法：人物以深色剪影和少量切面建立体积，树木、山峦、积雪以不规则多边形构成。画面使用明显的前景、中景、远景分层。

**色彩随情绪变化：** 逃亡时为深蓝、灰白；大熊出场时转为草绿、土黄；寒鸦登场重新转冷；铁匠铺以橙红色火光与黑褐色环境对比；离别时使用苍白的冬日光线。

音乐采用北欧民谣、弓弦乐器、低沉鼓点与环境风声相结合的风格。前半段神秘、庄严，中段温暖、克制，最后随里加的策马奔跑逐渐加速。

## 二、详细文字分镜

### 第一幕：火焰与逃亡

00:00—00:23 · 品牌开场、引入小说的现在时

**镜头 01｜00:00—00:04｜文舟启动**

- **画面：** 全黑背景。沿用文舟 0.9.8.1 宣传片的开场动画节奏，中央弹出“文舟 0.9.9”。文字周围出现极细的浅色轮廓，背后逐渐显现一张灰白色纸页。
- **镜头：** 固定机位，轻微推近。所有视觉元素由代码绘制，不采用真实软件录像。
- **声音：** 低沉的弓弦声响起，伴有轻微纸张摩擦声。暂时没有对白。

**镜头 02｜00:04—00:09｜燃烧的纸页**

- **画面：** 纸页右下角先出现一个黑褐色焦点，随后透出微弱橙光。火焰沿不规则边缘向上蔓延，烧焦的部分卷曲、脱落，露出下层幽蓝色的森林。
- **镜头：** 缓慢推近燃烧缺口，直到缺口扩张为整个画面。火星向镜头前方飘散。
- **声音：** 纸张燃烧的噼啪声逐渐被寒风取代。一个极其微弱的马蹄声从远处响起。

**镜头 03｜00:09—00:17｜松林里的里加**

- **画面：** 低机位远景。苍蓝色的积雪上散布着倒下的士兵、牲畜、折断的长矛和遗弃的剑。右侧是一棵粗大的松树，里加弓着身子跪在树根旁，手中紧握长枪。画面左下方是一匹倒下的马，只有深色轮廓，不刻意表现伤口。里加占据画面右侧三分之一，头低垂着。背景的松树笔直而安静，远处有一层冷色薄雾。
- **镜头：** 从宽阔的战场缓慢向右推进，在里加身上停下。
- **声音：** 低沉男声（成年里加）：

  > 我死死地攥着手里的长枪，弓着身子，跪在牲畜和人的尸体中……

  马蹄声愈来愈近，叠加在独白后方。

**镜头 04｜00:17—00:23｜寒风**

- **画面：** 切至里加侧脸特写。鼻尖上的汗珠被风吹得颤动，呼出的白气迅速向左散去。他的眼睛望向声音传来的方向，手指进一步攥紧枪杆。突然，风吹动地面积雪，雪粒从画面右方成片卷起。
- **镜头：** 从侧脸迅速拉远，雪尘填满整个画面，为转场作准备。
- **独白：**

  > 麦依尔曾对我说过，冬天是辛弗兰给予战士的怜悯。

### 第二幕：大熊与寒鸦

00:23—00:59 · 精魂世界观与词条功能

**镜头 05｜00:23—00:36｜大熊阿瑟**

- **画面：** 狂风携带整幅画面迅速向右滑动，冰雪转为绿色草地。原先近乎黑色的松树变成蓬勃的春季树林，天空露出淡黄色阳光。一只巨大的棕熊正站在画面中部偏左。它低头，鼻息吹向残余积雪，雪层融化，露出泥土和嫩草。随后大熊抬起前爪，直立起来，张嘴咆哮。咆哮时，草叶向两旁伏倒，画面边缘产生轻微震动。
- **镜头：** 先平行追踪大熊，随后随它直立略微上仰。
- **独白：**

  > 大熊阿瑟用它温暖的鼻息融化积雪，将露出的大地作为战场，吼叫着呼喊战争。

- **软件功能：** 伴随着“阿瑟”二字被念出，右上角出现文舟词条编辑浮层。鼠标选中“阿瑟”，点击“加入词条”，卡片展开，输入“阿瑟”“大熊精魂”，随后收起为一个小标签。这里的词条释义属于世界观展示文字，而不是软件自动生成的内容。

**镜头 06｜00:36—00:40｜春天升入冬天**

- **画面：** 大熊仍然保持站立，但画面开始向上移动。镜头越过树冠，绿色叶片逐渐稀疏、枯黄，最后被白霜和积雪覆盖。天空从温暖的浅黄蓝色逐渐变成冷白色。一抹暗红色从地面向外扩散，随即被白雪覆盖，象征鲜血与寒冬。
- **镜头：** 连续垂直上移，不进行硬切。
- **独白：**

  > 而当战士们的血浸染大地时……

**镜头 07｜00:40—00:55｜寒鸦辛弗兰**

- **画面：** 镜头停在一根向画面左侧伸展的黑色树枝上。一只寒鸦缩着脖子站在枝头，身体呈深蓝黑色，鸟喙尖锐。它先向下俯视，随后猛然张开翅膀，从树枝上跃起。随着第一下振翅，背后的远山变暗；第二下振翅，雪花从屏幕右上方席卷而来；第三下振翅，山岭、树林和草地都被寒风吞没。最终，寒鸦从镜头前方掠过，巨大的黑色翅膀短暂遮蔽整个画面。
- **镜头：** 固定机位捕捉寒鸦起飞，随后跟随其运动略微上升。
- **独白：**

  > 辛弗兰就用它的翅膀扇起寒风，用寒冷与死亡恐吓战士们，让他们对战争望而却步。

- **软件功能：** 寒鸦展翅时，左上角选中“辛弗兰”，出现词条浮层，建立“辛弗兰｜寒鸦精魂”，显示保存成功后自然淡出。
- **声音：** 低频风声覆盖大熊的咆哮，弓弦乐停止，留下清脆而空旷的高音。

**镜头 08｜00:55—00:59｜从寒雪到炉火**

- **画面：** 寒鸦翅膀掠过之后，空中飞舞的白色雪粒忽然被一团暖光照亮，逐个变成橙红色火星。一枚火星从画面中心落下，在落地的一瞬间切为铁砧上飞溅的真实火星。
- **镜头：** 跟随一枚粒子的下落，利用颜色和运动方向完成匹配转场。
- **独白：**

  > 在今天之前，我都不曾领会这种仁慈。

### 第三幕：铁匠与少年

00:59—01:27 · 哈沃德与里加、人物关系功能

**镜头 09｜00:59—01:11｜铁匠铺里的火**

- **画面：** 特写。哈沃德厚实的手掌握着铁锤，一块接近白色的铁片横放在铁砧中央。铁锤落下，铁片边缘微微变形，火星以不规则的多边形碎片向外迸射。前两次落锤画面保持明亮，第三次落锤时，镜头后移，露出深褐色的工坊。炉子在左后方燃烧，墙边摆放着锻造工具。年少的里加站在铁砧另一侧，手里拿着工具。他并没有认真看哈沃德的动作，目光始终追逐那些正在熄灭的火星。
- **镜头：** 连续三次落锤使用不同景别，最后一次由特写拉至双人中景。
- **独白：**

  > 每当我看着他用锤子砸在烧得发白的铁块上，滋滋作响的火星飞着溅射出来，我眼睛就移不开了。

- **声音：** 锻造敲击声与音乐低音鼓点重合。

**镜头 10｜01:11—01:22｜关系的建立**

- **画面：** 哈沃德继续敲打铁块，里加在旁边俯身打下手。镜头缓慢横移，使两人占据画面下方，留出上方的空白。随后文舟的人物关系界面以半透明图层展开。上方先出现一个标记为“里加”的节点，再出现“哈沃德”的节点。两者以一条线连接，连线上注明“抚养与照料”。节点连线刚刚完成，背景里的哈沃德停下手中的动作，转头看着里加。里加则仍然盯着一枚落在地上的火星。
- **镜头：** 人物保持侧透视构图，软件界面固定在屏幕空间，不跟随背景运动。
- **独白，成年里加：**

  > 我害怕它们，但我的眼睛却会被它们吸引。

- **对白，哈沃德（中年人，平和而朴实）：**

  > 你会习惯的，人总是会习惯的。

  这里不用“父子关系”作节点标签，因为原文明确强调，两人的关系并不能简单地用父子或养父子来定义。

**镜头 11｜01:22—01:27｜离开工坊**

- **画面：** 里加俯视地上的火星。最后一枚火星从暗红变成灰黑，随之出现一个小小的白点。白点扩散成为落下的雪花。画面由铁匠铺的黑褐色向冬日的灰白色过渡。哈沃德和里加的剪影在雪地中慢慢显现，工坊的背景消失。
- **镜头：** 固定构图，以火星与雪花的形状进行交叠转场。
- **声音：** 最后一记锤声留下混响，逐渐化为马匹的鼻息和脚踩积雪的声音。

### 第四幕：漫长的告别

01:27—02:08 · 人物对白与地图绘制功能

**镜头 12｜01:27—01:38｜出村的路**

- **画面：** 远景。白雪覆盖的道路向画面右侧延伸，两边是一排排黑色树干。哈沃德在前面牵着马，里加坐在名叫皮培的马背上。两人缓慢从左侧进入画面。马蹄踩出弯弯的脚印，哈沃德的皮靴留下另一排较深的痕迹。远处太阳被乌云遮住，整个画面随之变暗。哈沃德在道路交叉处停下，松开缰绳，转身抬头看着里加。
- **镜头：** 起初是远景，随着两人移动缓慢推进为中远景。
- **对白，哈沃德：**

  > 就到这儿吧，从这里去海尔加德，一直骑上半天也就到了，不算远。

**镜头 13｜01:38—01:56｜哈沃德的嘱咐**

- **画面：** 哈沃德抬起手，向道路远方指去。里加顺着他的手望去。随着他开始说话，远景中的森林与山坡渐渐平面化，转变为一张中世纪绘图风格的地图。地图并不是突然弹出一个方框，而是直接从画面背景上生长出来。地图上首先出现标记“萨卡莱特”的村落图案，随后沿着一条蜿蜒道路依次绘制出“艾洛夫”“盎讷”“海尔加德”。森林由一个个深绿色多边形树木组合形成，河流由曲线描绘。每当哈沃德提到地名，地图上就出现对应标记，细线将各地连接起来。哈沃德和里加仍然站在画面下方，不随地图改变形态。
- **镜头：** 双人中景逐渐拉远，让地图成为主画面。
- **对白，哈沃德：**

  > 但你别一直骑，从这里再骑上一会儿就到艾洛夫，再过去就是盎讷了，你在盎讷休息一下，停上半天，这样你明天或是后天再到海尔加德。

- **软件功能：** 地图绘制控件随对白依次建立地点标记和道路连线。可以短暂出现绘制工具栏，但不遮挡人物表情。

**镜头 14｜01:56—02:08｜拥抱**

- **画面：** 地图缓慢隐去，重新显现雪地。里加忽然从马背上跳下来，落地时扬起少量积雪。他向哈沃德走近一步，伸出双手抱住他。哈沃德稍微一怔，随后也伸出双臂抱紧里加。两人保持这个姿势。背景的雪花缓缓下落，音乐暂时安静下来。哈沃德轻轻拍了拍里加的后背，里加才松开手。哈沃德转过头去看远方，像是在确认天气，随后对里加说话。
- **镜头：** 从双人全景轻微推进至半身景，最后停留在拥抱的剪影上。
- **对白，哈沃德：**

  > 我总在这儿，你别怕找不到我。

- **声音：** 几乎只留下风声。最后一个“我”字结束后保持短暂寂静。

### 第五幕：奔向未知

02:08—02:41 · 骑行、大纲功能与黑暗转场

**镜头 15｜02:08—02:17｜策马**

- **画面：** 里加重新翻身上马。哈沃德站在道路左侧，抬头看着他。里加握紧缰绳，轻轻踢了一下皮培的肚子。皮培迈步，随后开始小跑。少年忽然露出兴奋的神情，身体向前弯曲，再次催促皮培。马的四蹄先后离地，奔跑动作变得舒展而快速。哈沃德的身影迅速向画面左侧退去，越来越小，最后被树干遮住。
- **镜头：** 从双人全景转为跟踪里加的侧面镜头。里加始终保持在画面左侧约四分之一处。
- **对白，少年里加：**

  > 驾！

- **声音：** 音乐由缓慢弓弦转入更强的节奏，马蹄声配合鼓点不断加速。

**镜头 16｜02:17—02:31｜流动的世界**

- **画面：** 皮培高速奔跑，里加压低身体、紧贴马颈。里加与马匹始终位于画面左侧，位置基本不变，树木、雪丘与山岭则以不同速度从右向左移动。近处树干快速划过，中景道路不断向后延伸，远处的山仅缓慢移动，营造速度感。随着奔跑趋于稳定，画面右侧出现文舟大纲面板。大纲面板依次展开节点：“逃亡的松林”“大熊阿瑟”“寒鸦辛弗兰”“哈沃德的铁匠铺”“离开萨卡莱特”“前往海尔加德”。新节点逐个加入，与上层章节相连，形成逐渐扩展的树状结构。节点连线的出现与马蹄节奏一致。
- **镜头：** 持续平行跟踪，不进行切换。左侧的骑行画面与右侧的大纲界面形成稳定的双区构图。
- **声音：** 无新对白，留给音乐与软件功能展示。

**镜头 17｜02:31—02:36｜最后的回忆**

- **画面：** 大纲面板完成最后一个节点后，所有节点收拢到一个章节标题中，缓缓向右淡出。里加仍旧向右飞奔，衣服被风吹起，马蹄连续敲击地面。此时画面从明亮的雪地渐渐进入阴暗的森林。原本位于左侧的里加不再被镜头完全锁定，整个背景加速向左移动。
- **独白，成年里加，沉静地说：**

  > 而在这之后，我也再没见过哈沃德。

**镜头 18｜02:36—02:41｜奔入黑暗**

- **画面：** 前方出现一片巨大的黑色树荫。皮培仍向右飞奔。里加没有勒马，而是继续俯身加速。他们穿过阴影边缘，身上的色彩迅速变暗。最后，只剩下少许灰白的轮廓。整个人马剪影冲进漆黑的画面，完全消失。
- **镜头：** 画面整体持续左移，跟随人马运动的视线停在黑暗入口，直至全黑。
- **声音：** 马蹄声在最后一个强鼓点时戛然而止，仅剩短暂风声。

### 第六幕：文舟

02:41—02:49 · 产品落版

**镜头 19｜02:41—02:49｜终幕**

- **画面：** 黑暗中出现一枚暖白色微光。光芒缓缓扩散，形成文舟 Logo。随后出现标题：文舟 / 0.9.9 / 让故事，自此起航。/ 现已上架鸿蒙应用市场。背景保留几枚从下方缓慢飘起的橙红色火星，与开篇燃烧的纸页呼应。

## 三、关键声音与功能节奏

**配音安排：** 成年里加使用低沉、疲倦、带有回忆感的男声；少年里加使用明亮、略显急躁的声音；哈沃德则使用朴实而缓慢的中年男声。成年里加的独白不能像英雄史诗的旁白那样激昂。他是在回忆自己曾经相信、害怕并且失去的一切。

**音乐卡点：**

| 时间 | 卡点 |
| ----- | ------------ |
| 00:09 | 火焰退去，马蹄声进入 |
| 00:23 | 风声推动春季场景出现 |
| 00:40 | 寒鸦起飞，音乐升高 |
| 00:59 | 锻造锤第一次重击 |
| 01:56 | 地图消失，音乐渐弱 |
| 02:08 | 里加跃上马背，节奏加速 |
| 02:41 | 突然安静，Logo 出现 |

**功能露出方式：** 词条功能跟随精魂名称出现，人物关系跟随铁匠铺场景出现，地图跟随哈沃德的指路出现，大纲则在里加策马时集中展示。这样四项功能都来自叙事本身，而不是额外插入的说明画面。

## 四、代码动画制作建议

| 元素 | 实现方式 |
| -------- | ------------------ |
| 人物 | 分层多边形骨骼动画，面部保留少量特征 |
| 熊、寒鸦、马匹 | 预先定义关键姿态，使用程序插值 |
| 森林、雪地、远山 | 多层视差背景与可复用地形模块 |
| 火焰、火星、雪花 | 粒子系统与不规则形状变换 |
| 镜头移动 | 统一虚拟摄像机控制坐标偏移与缩放 |
| 软件功能演示 | 独立界面图层，叠加于故事画面之上 |
| 地图及大纲 | 节点、曲线、连线的逐帧生成动画 |

特别是熊的咆哮、寒鸦的振翅和马的奔跑，建议先确定关键姿势及动作周期，再制作补间动画。

## 五、最值得保留的三个设计

1. **精魂转换。** 阿瑟代表春天、战场和战争的召唤，辛弗兰则代表寒冬、死亡对战士的警告。这段正好能够让词条功能以具有象征意义的方式登场。
2. **哈沃德和里加的关系。** 原著里真正令人动容的地方，并不是两人说了什么感人的话，而是哈沃德始终把分别视为一件很平常、随时可以逆转的小事。因此拥抱镜头不需要夸张表演，越平静越好。
3. **结尾的声音反差。** 在里加奔跑、大纲已经收起之后，才让成年里加说出“而在这之后，我也再没见过哈沃德。”这句出自原文的回忆会瞬间改变观众对离别场景的理解。

整支宣传片的核心是：用一个少年的离乡故事展示文舟如何承载一部小说的世界、人物、地理和情节。文舟是故事的记录者，而不是打断故事的讲解者。
