# 文舟 0.9.9 宣传片 ·《炉火祈愿》

以《炉火祈愿》第一部为叙事主体的二维动画短片，2 分 49 秒，16:9（1920×1080，30 fps）。分镜见 [storyboard.md](storyboard.md)。

成片：`炉火祈愿-文舟0.9.9宣传片.mp4`（按第一版分镜制作）

> 分镜已改为第六版（全片统一为阿瑟与辛弗兰的织法，不出现人物，两根线一路织到结尾），美术设定与关键帧见 [storyboard.md](storyboard.md)。第四版待审核通过后再渲染成片；下文“画面”一节描述的仍是第一版成片。织锦渲染器在 `samples/loom.js`，关键帧脚本在 `storyboard/`。

## 画面

全部画面由代码绘制在 Canvas 2D 上，不使用真实软件录像或外部素材。

- 造型参照《Out of this World / Another World》：人物和动物按真实比例勾出准确的外轮廓，内部用大块平涂色块填色，每个部位只分受光与背光两个色调。
- 人物不画五官，脸部用肤色平涂。成年人约八头半身，胯关节在身高一半处。
- 躯干轮廓按胸廓、腰、骶骨、臀部走线；四肢按骨骼走向描出三角肌、肱二头肌、前臂、股四头肌、腘绳肌和小腿腓肠肌的曲线；姿势由两段式 IK（反向动力学）解算。
- 马按真实马体比例绘制：鬐甲高 150，体长与体高相当，腹线在半高。腿分三段（前臂或胫部、管部、系部），飞节高而后突；栗色马的下肢、鬃毛和尾为黑色。
- 熊有肩峰、后背下斜、头低，四肢厚重、整足着地；人立时换成直立轮廓，与四足轮廓逐点插值过渡。
- 寒鸦从侧面看时，翅膀绕身体纵轴扇动，因此经过水平位置时会透视缩短。

文舟界面层（术语库、人物关系 `.pcs`、地图 `.vlmp`、大纲 `.pcs`）使用应用的配色与用词，例如“加入术语库”“词条已加入术语库”。

## 声音

- 配乐为原创，在 `soundtrack.py` 中合成：北欧民谣风格，弓弦乐（持续低音与旋律）、拨弦（康特勒琴）、框鼓和风声，按分镜第三节的卡点编排。
- 音效同样全部合成：纸页燃烧、马蹄、熊的咆哮、寒鸦振翅与鸣叫、锻锤与火星、雪地脚步等。
- 疾驰段的鼓点和马蹄与画面中马的步态由同一条速度曲线（`lines.js` 的 `gallop`）驱动，因此严格同步。
- 配音为英语，由 Kokoro-82M（Apache-2.0）在本地合成：

| 角色 | 声音 | 说明 |
| --- | --- | --- |
| 成年里加 | `bm_lewis`，0.88 倍速 | 低沉、疲倦的回忆 |
| 少年里加 | `am_puck` | 明亮 |
| 哈沃德 | `bm_george`，0.86 倍速 | 朴实、缓慢的中年男声 |

字幕为中英双语，中文为小说原文。若改用真人配音，把录音按相同编号放进 `voice/` 后重新运行 `soundtrack.py` 即可。

## 文件

| 文件 | 作用 |
| --- | --- |
| `lines.js` | 时间线：19 个镜头、台词与字幕、配音演员、马的步速曲线、锻锤时刻；所有脚本共用 |
| `scene.html` | 画布、绘图基础、人物与动物模型、文舟界面层、字幕；可直接在浏览器中打开预览（含声音） |
| `scenes.js` | 19 个镜头的绘制 |
| `voice.py` | 生成 `voice/*.wav` 与 `voice/timing.js` |
| `soundtrack.py` | 配乐、音效与配音混音，生成 `soundtrack.wav` |
| `render.mjs` | 逐帧渲染并与 `soundtrack.wav` 合成 MP4；也可以导出静帧、联系表或角色模型表 |
| `fonts/` | 思源宋体（Noto Serif SC，SIL OFL 1.1）按本片用字裁剪后的子集，以及裁剪脚本 |

## 重新生成

在仓库根目录运行：

```sh
pip install kokoro-onnx soundfile numpy scipy fonttools brotli
python3 promo/0.9.9/voice.py          # 配音（模型与声音从 npm 下载，缓存在 dist/promo）
python3 promo/0.9.9/soundtrack.py     # 配乐 + 音效 + 配音 → soundtrack.wav
python3 promo/0.9.9/fonts/subset.py   # 只在改动文字后需要
node promo/0.9.9/render.mjs           # → 炉火祈愿-文舟0.9.9宣传片.mp4
```

渲染需要 Playwright、ffmpeg（或设置 `FFMPEG=…`）和 Chrome/Chromium（Windows 默认使用已安装的 Chrome，也可设置 `WENZHOU_CHROME=…`）。

检查画面的辅助命令：

- `node promo/0.9.9/render.mjs stills 20,61.5`：导出指定时刻的静帧
- `node promo/0.9.9/render.mjs sheet 0,10,20,…`：导出联系表
- `node promo/0.9.9/render.mjs chars`：导出角色模型表
