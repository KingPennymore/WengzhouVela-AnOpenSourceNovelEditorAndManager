# 文舟 0.9.9 宣传片 ·《炉火祈愿》

以《炉火祈愿》第一部为叙事主体的织锦动画短片，2 分 49 秒，16:9（1920×1080，30 fps）。分镜与美术设定见 [storyboard.md](storyboard.md)（第七版），关键帧见 `storyboard/frames/`。

成片：`炉火祈愿-文舟0.9.9宣传片.mp4`

## 画面

开场与落版沿用 0.9.8 宣传片的 Logo 样式。开场的 Logo 从四角烧开，露出一幅挂毯；此后全片都织在挂毯上，画面中不出现人物。

- **织法：** 统一为阿瑟、辛弗兰两段的织法。
  - 经距 6 px、纬高 4 px 的粗织；
  - 植物染料色板，两色交界处梳齿状交错，同色有染缸批次的深浅条纹；
  - 动物与物件都是单色剪影：深色勾边，内侧第二道轮廓线，关节处有螺旋纹；
  - 树为卷枝纹样；
  - 上方是拉丁铭文花边（“HIC……”），下方是菱格花边；
  - 炉火光从左下方照来，随火焰明灭。
- **镜头：** 镜头在布面上移动。推近时织纹随之放大；横移和上移时，纬线始终固定在图案上，不会在画面里爬动。换姿态时，新画面在一条扫描线后从上到下重新织出，像织机那样。
- **人物：** 哈沃德和里加只以痕迹出现。
  - 第一幕是大树旁的长枪、红布条和从树后吹出的呼吸；
  - 铁匠铺是铁砧上一块白热的铁；
  - 离乡的一段是两根线：哈沃德是草绿色，里加是菘蓝色。两根线沿雪路向上织，在岔路口缠绕；“驾！”之后蓝线向上跑去，绿线留在原地；最后蓝线跑进挂毯上方还没有织的经线。

文舟界面层（术语库、人物关系 `.pcs`、地图 `.vlmp`、大纲 `.pcs`）保持应用本身的配色，叠在织锦上方。

## 声音

- **配乐：** 原创，在 `soundtrack.py` 中合成：北欧民谣风格，弓弦乐（持续低音与旋律）、拨弦（康特勒琴）、框鼓和风声，按分镜的卡点编排。
- **音效：** 同样全部合成：燃烧、马蹄、熊的咆哮、寒鸦振翅与鸣叫、铁块的嘶嘶声、雪地脚步等。
- **疾驰段：** 鼓点、马蹄与蓝线的每一次向前跃进由同一条步速曲线（`lines.js` 的 `gallop`）驱动，严格同步。
- **配音：** 英语，由 Kokoro-82M（Apache-2.0）在本地合成：

| 角色 | 声音 | 说明 |
| --- | --- | --- |
| 成年里加 | `bm_lewis`，0.88 倍速 | 低沉、疲倦的回忆 |
| 少年里加 | `am_puck` | 明亮 |
| 哈沃德 | `bm_george`，0.86 倍速 | 朴实、缓慢的中年男声 |

字幕为中英双语，中文为小说原文。若改用真人配音，把录音按相同编号放进 `voice/` 后重新运行 `soundtrack.py` 即可。

## 文件

| 文件 | 作用 |
| --- | --- |
| `lines.js` | 时间线：19 个镜头、台词与字幕、配音演员、马的步速曲线、步行时刻；所有脚本共用 |
| `scene.html` | 画布与绘图基础、字幕；依次载入下列脚本；可直接在浏览器中打开预览（含声音） |
| `scenes.js` | 文舟界面层（术语库、人物关系、地图工具栏、大纲）与第一版成片的镜头（已不再使用） |
| `samples/loom.js` | 织机：织造网格、染料色板量化、交错与染色条纹、毛线肌理、炉火光；`wFigure` 剪影 |
| `samples/samples.js` | 美术风格样图及其中的大熊等造型 |
| `storyboard/frames.js` | 第七版分镜的各幅图案与关键帧 |
| `film.js` | 成片：把分镜的图案按时间做成动画，`renderAt(t)` 画出任意时刻 |
| `voice.py` | 生成 `voice/*.wav` 与 `voice/timing.js` |
| `soundtrack.py` | 配乐、音效与配音混音，生成 `soundtrack.wav` |
| `render.mjs` | 逐帧渲染并与 `soundtrack.wav` 合成 MP4；也可以导出静帧或联系表 |
| `fonts/` | 思源宋体（Noto Serif SC，SIL OFL 1.1）按本片用字裁剪后的子集，以及裁剪脚本 |

## 重新生成

在仓库根目录运行：

```sh
pip install kokoro-onnx soundfile numpy scipy fonttools brotli
python3 promo/0.9.9/voice.py               # 配音（模型与声音从 npm 下载，缓存在 dist/promo）
python3 promo/0.9.9/soundtrack.py          # 配乐 + 音效 + 配音 → soundtrack.wav
python3 promo/0.9.9/fonts/subset.py        # 只在改动文字后需要
node promo/0.9.9/render.mjs                # → 炉火祈愿-文舟0.9.9宣传片.mp4
node promo/0.9.9/storyboard/render.mjs     # 分镜关键帧 → storyboard/frames/*.jpg
python3 promo/0.9.9/storyboard/sheet.py    # → storyboard/contact-sheet.jpg
```

渲染需要 Playwright、ffmpeg（或设置 `FFMPEG=…`）和 Chrome/Chromium（Windows 默认使用已安装的 Chrome，也可设置 `WENZHOU_CHROME=…`）。在本机约每帧 0.3 秒，全片约半小时。

检查画面的辅助命令：

- `node promo/0.9.9/render.mjs stills 20,61.5`：导出指定时刻的静帧
- `node promo/0.9.9/render.mjs sheet 0,10,20,…`：导出联系表

## 与小说和分镜的出入

- 配音为英语（按制作时的要求），字幕保留中文原文并附英文。
- 分镜中的“加入词条”在画面中写作应用里的实际菜单项“更多 → 加入术语库”。
- 镜头 17 保留了“而在这之后，我也再没见过哈沃德。”这句独白。
- 拉丁铭文为本片所加，用以模仿贝叶挂毯的“HIC……”题记。
