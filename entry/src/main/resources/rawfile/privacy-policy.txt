文舟 Vela 隐私政策

更新日期：2026 年 10 月 29 日　生效日期：2026 年 10 月 29 日

文舟（Vela，包名 me.wenzhou.write，以下简称“本应用”）是由个人开发者 KingPennymore 维护的开源小说创作与阅读工具。我们重视你的个人信息保护。请在使用前仔细阅读本政策；你点击“同意”即表示已阅读并同意本政策，点击“拒绝”则不会使用本应用，也不会收集任何信息。

一、我们不做什么

- 本应用没有账号体系，不要求注册或登录本应用。
- 本应用不集成任何广告、统计分析、崩溃上报或第三方 SDK，不向开发者的服务器上传任何数据（开发者没有运营服务器）。
- 我们不会出售、出租或向第三方共享你的个人信息。

二、本应用处理的信息

• 你创建、导入的文稿、附件、书签、批注与应用设置
  用途：实现写作、阅读、历史恢复
  存放：仅保存在本机应用沙箱，不上传；卸载应用后删除
• 你主动选择导入的本地文件、你主动导出的文件
  用途：导入、导出
  存放：仅在你操作时读取或写入你指定的位置
• 剪贴板内容
  用途：仅在你点击“粘贴”等操作时读取（权限 READ_PASTEBOARD，使用场景：应用在前台）
  存放：不保存、不上传
• GitHub / Gitee 访问令牌（仅在你主动登录仓库功能时）
  用途：访问你授权的代码托管平台
  存放：保存在系统安全存储中，不经过开发者；可在应用内退出登录删除
• AI 服务 API Key（仅在你配置 AI 助手时）
  用途：代你访问你选择的 AI 服务
  存放：保存在系统安全存储中，界面无法再读取，不经过开发者；可在 AI 设置中删除

本应用不收集你的设备标识符（如 OAID、IMEI）、位置、通讯录、相册、麦克风、摄像头等信息，也不申请这些权限。

三、网络访问与第三方服务

本应用申请网络权限（ohos.permission.INTERNET），仅在你主动使用下列功能时联网，请求直接发往对应服务，不经过开发者服务器：

1. GitHub / Gitee 仓库同步与订阅：向 github.com、api.github.com 或 gitee.com 发送你的令牌及你选择同步的仓库内容。这些平台按其各自的隐私政策处理数据。
2. 可选组件与更新下载（如 TeX 排版组件、版本检查）：从 GitHub 或 Gitee 发布页下载文件，平台可能记录你的 IP 地址等访问日志。
3. AI 助手（可选，默认关闭）：你在设置中启用并配置后，仅在你主动使用时，把你选择的章节，或开启续写建议后光标前设定范围内的文字，连同你的 API Key 直接发送给你配置的 AI 服务（例如 OpenAI、Anthropic、Google、DeepSeek、阿里云百炼，或你本机运行的模型）。这些服务按各自的条款和隐私政策处理数据，并可能向你收费；本应用开发者不经手、不保存这些内容。你可以随时在设置中关闭 AI 助手或删除密钥。

不使用这些功能时，本应用可完全离线运行。

四、权限说明

- 网络：用于上述第三方仓库同步、组件下载，以及你启用的 AI 助手。
- 读取剪贴板：仅在你主动粘贴时使用。

你可以随时在系统设置中管理权限；拒绝权限只会使对应功能不可用。

五、信息存储、保护与保留

数据保存在本机，存储期限为你使用或卸载本应用之前。令牌与 AI 服务密钥存放在系统安全存储。你可随时在应用内删除文稿、清除登录状态，或卸载应用以删除全部本地数据。导出的备份与同步到第三方平台的内容由你自行管理。

六、你的权利

由于我们不在服务器上持有你的个人信息，你可以直接在本机查阅、更正、导出和删除全部数据；也可撤回同意（在系统“设置 > 应用和元服务”中清除应用数据或卸载，之后再次打开会重新征求同意）。

七、未成年人

本应用不面向 14 周岁以下儿童提供服务。如果你是未成年人，请在监护人同意并指导下使用。

八、政策更新

政策发生变更时，我们会在本页更新并在应用内再次征求你的同意。
