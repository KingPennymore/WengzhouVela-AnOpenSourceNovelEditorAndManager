# 界面重构

文舟界面的统一与精简方案，分五个阶段落地。每个阶段独立可验证、可回退。设计变量和组件规格以本文为准；实现细节写进各阶段的提交说明。

## 现状（2026-10-29 走查）

- 样式表有 28 种字号（9–28 px，其中 9/10/11 px 合计约 100 处）、29 种圆角、153 种内边距、35 种阴影；颜色、动效、阴影层级已有变量，字号、间距、圆角、控件高度没有。
- 设置页：说明文字被 `organizeSettings` 留在原地而落进“备份与应用”；导出与恢复备份被拆开；复选框画成圆形，像单选；两三个选项也用整行下拉框；同一页混用三种容器；对话框叫“编辑器设置”而启动页叫“设置”；手机上面板只占屏幕约 60%，分类标签同时两个高亮、最后一项被挤出屏幕。
- 手机编辑页：正文上方四层操作栏加状态栏约 220 px；底栏 8 个图标，四个跳转图标难以区分。
- 启动页：8 张同等分量的入口卡；“继续写作”不突出；触屏也显示“命令与快捷键”。
- 桌面主导航只有图标，没有文字。

## 设计变量（阶段 1）

在 `web/style.css` 的 `@layer tokens` 中定义，组件与页面只用变量：

| 类别     | 变量                                                        | 取值                                                                        |
| -------- | ----------------------------------------------------------- | --------------------------------------------------------------------------- |
| 字号     | `--text-xs` `--text-sm` `--text-md` `--text-lg` `--text-xl` | 12 / 14 / 16 / 20 / 24 px（正文字号仍由用户设置 `--editor-font-size` 决定） |
| 行高     | `--leading-tight` `--leading` `--leading-loose`             | 1.3 / 1.5 / 1.75                                                            |
| 字重     | `--weight-regular` `--weight-medium` `--weight-bold`        | 400 / 500 / 600                                                             |
| 间距     | `--space-1` … `--space-6`                                   | 4 / 8 / 12 / 16 / 24 / 32 px                                                |
| 圆角     | `--radius-sm` `--radius-md` `--radius-lg` `--radius-full`   | 6 / 10 / 16 / 999 px（现有 `--radius` 改为 `--radius-md` 的别名，逐步替换） |
| 控件高度 | `--control-h`                                               | 桌面 36 px；`(pointer: coarse)` 下 44 px（触屏点击区域下限）                |
| 阴影     | 沿用 `--elev-1/2/3`                                         | —                                                                           |

手机上界面文字最小 12 px；徽标、计数等极少数例外需在代码注释说明理由。

## 基础组件（阶段 1）

放在 `web/ui-components.css`（或 `style.css` 中独立一节）与 `web/ui-components.mjs`（只放需要脚本的组件），并在 `docs/UI-COMPONENTS.md` 写用法、在一个演示页（可扩展现有 `tests/components-browser.mjs` 用的页面或新增 `web/ui-gallery.html` 仅供开发）展示全部状态：

- 按钮：主要、次要、文字、危险；常规与紧凑两档；禁用态统一（降低不透明度，不换色）。
- 开关按钮（Switch）：替代表示开/关的复选框，`<input type="checkbox" role="switch">` 加样式，保持原生表单行为。
- 分段按钮：一组 `radio` 的样式，用于 ≤4 个选项。
- 下拉框：沿用 `app-choices`，统一外观。
- 步进器：`− 值 +`，用于字号等数字。
- 设置行：名称 + 一行说明 + 控件；桌面控件在右，窄屏在下一行。
- 卡片、列表行、空状态、加载中、加载失败可重试（统一 `chunkLoading`/`chunkFailure` 外观）、提示条。
- 图标按钮：必须有可读名称；桌面悬停显示提示。
- 对话框与底部弹出层：手机为底部弹出层，可选全屏；桌面居中。

## 设置页（阶段 2）

### 分组

| 分组       | 内容                                                                            | 控件                                                  |
| ---------- | ------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 外观       | 主题、配色、字体、界面语言                                                      | 主题与语言用分段按钮；配色用色卡网格；字体下拉 + 预览 |
| 编辑       | 正文字号、TXT 格式工具、小说模式行号                                            | 步进器、开关                                          |
| 补全与术语 | 名词候选补全、术语高亮与释义、正文与术语库同屏                                  | 开关，每项带说明                                      |
| 章节与字数 | 字数规则、字数含标题、章节识别说明与模板入口                                    | 分段按钮、开关、链接                                  |
| 阅读       | 阅读方式、统一使用我的阅读排版；“高级”中编辑全局 `.vela`                        | 三张示意卡片、开关、折叠项                            |
| AI 助手    | 状态卡（未启用 / 已连接 服务 · 模型）+ 开关；服务与密钥、模型、用量三小块       | 打开开关时弹一次数据发送确认，不常驻页面              |
| 存储与同步 | 创建 `.vela`、清除冗余文件                                                      | 按钮 + 说明                                           |
| 备份与关于 | 导出 / 恢复备份（并排）、版本、检查更新与自动检查、隐私政策、开源许可、操作指南 | 列表行                                                |

对话框与入口统一叫“设置”。

### 布局

- 手机：全屏页面。第一层为分类列表（图标、名称、当前摘要，如“外观 · 跟随系统 · 青松”），点入为详情页，系统返回键与左上返回回到上一层。
- 桌面：左侧分类、右侧只显示当前分类；分组标题用 `--text-lg`。
- 改动即时生效，去掉“确定 / 取消”；需要验证的项（AI 密钥）保留自己的按钮。

### 实现

- 用设置项清单取代 `app.js` 中的大段 HTML 模板与 `organizeSettings` 的 DOM 搬移：每项声明分组、类型、名称、说明、`get()`、`set(value)`（立即生效并保存）。由独立模块（如 `web/settings-view.mjs`，按需加载）渲染。说明文字与控件在同一个元素中，不会再错位。
- 现有每项设置的副作用（`setLanguage`、`applyTheme`、`setFontSize`、`refreshGutters`、全局 `.vela` 写回、阅读器重排等）逐项搬进各自的 `set()`；保持现有存储字段与 `.vela` 结构不变。
- AI 部分复用 `web/ai-settings.mjs` 的逻辑，改成清单项与子页面。
- 删除 `organizeSettings`；更新受影响的测试（`config-v2`、`ui-overhaul`、`language-switch`、`palette`、`app-core-fonts`、`ai-assistant`、`workspace` 等）。

## 手机编辑页（阶段 3）

- 目标：正文上方与下方操作栏合计 ≤ 140 px（390×844）。
- 只开一个文稿时文件标签并入顶栏显示文稿名；多文稿时保留标签行。
- 格式工具栏默认收起，选中文字或点“Aa”时出现。
- 底栏保留撤销、重做、“跳转”（菜单含开头、结尾、本章开头、本章结尾、目录）；保存按钮改为保存状态指示（已有自动保存），点按仍可立即保存。
- 沉浸写作：连续输入时收起上下操作栏，向上滑动或点按屏幕上下边缘恢复；遵守“减少动态效果”。
- 桌面不受影响（或只做对应的视觉统一）。

## 启动页（阶段 4）

- 顶部“继续写作”大卡片：上次文稿、章节、今日字数，点按回到上次光标。
- 直接列出最近 3–5 个文稿。
- 其余入口改为次要按钮网格；触屏隐藏“命令与快捷键”。
- 三个统计数缩为一行。
- 桌面主导航在宽屏显示文字标签，窄屏保留图标并有提示。

## 全面替换与走查（阶段 5）

- 把样式表中写死的字号、圆角、间距、控件高度替换为变量；无法对应的值逐一确认后调整到最近一档。
- 新增检查（单元测试或浏览器测试）：禁止在 `web/*.css` 中出现变量以外的字号与圆角（列出少量白名单）。
- 深色模式逐组件检查；所有触屏可点区域 ≥ 44 px；焦点框统一；图标按钮有可读名称；新动画遵守减少动态效果。
- 统一命名与文案：按钮以动词开头，说明句末用句号，错误提示写清发生了什么、下一步做什么。

## 验证

- 每个阶段：`npm test` 全过；`npm run build` 后 `npm run test:browser` 全过（安卓与精简版套件按惯例跳过）。
- `tests/css-refactor-equivalence-browser.mjs` 用于“重构不改外观”。本次是有意改外观：每个阶段结束时把基准更新为该阶段合并后的提交（`CSS_BASE_REF`/默认值），并在提交说明中写明。
- 每个阶段新增或更新关键页面的截图对比（手机 390×844 安卓界面、桌面 1280×850，浅色与深色），截图存入 `test-results/ui-redesign/<阶段>/` 供人工核对。
