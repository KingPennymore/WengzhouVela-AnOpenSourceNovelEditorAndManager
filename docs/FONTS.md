# 字体选择

打开“设置 → 外观与语言 → 字体”，选择字体并点“确定”。选择结果应用于界面、正文编辑和普通阅读，重启后保留。

- “文舟默认”：保留原来的字体顺序。
- “跟随系统字体”：使用设备 WebView 的系统界面字体。
- “获取系统字体”：列出系统开放给应用使用的字体族。原生应用打开设置时自动读取，浏览器需点按钮，可能要求授权。

字体列表下方可以预览中英文和数字。取消设置不会更换当前字体；列表加载失败也可以使用默认或跟随系统。
只支持已安装且系统对应用开放的字体，不下载字体，也不修改系统字体设置。

Windows 读取本机字体族，包括系统开放的用户安装字体。鸿蒙按系统版本读取字体配置及图形接口中的字体族。
Android 读取系统公开的命名字体族和别名；主题商店字体或未公开的字体文件不保证出现在列表中。
浏览器的支持范围及授权由浏览器决定。

选择保存在工作区的个人设置 `settings.fontFamily` 中；作品 `.vela` 不写入此项。
迁移到其他设备后若该字体不存在，按系统字体回退，仍保留原来的选择，允许在设置中恢复默认。
富文本中的宋体、楷体等指定样式、代码区的等宽字体，以及 HTML / PDF / LaTeX 自身排版保持各自规则。

实现边界见 [ADR 0002](adr/0002-system-font-selection.md)。
