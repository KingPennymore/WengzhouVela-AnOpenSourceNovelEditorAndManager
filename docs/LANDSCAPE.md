# 横屏与 PC 窗口布局

横屏优化在面板操作与保形精简功能完成后单独实施，保留文舟原有配色、图标、动效和插件区域。全部样式位于 app 层，不给滚动容器添加背景。

## 手机和平板

- 高度不超过 520 px 的横屏保留文件标签，压缩顶栏与工具栏的上下留白，图标操作仍保持 44 px 高度。恢复标签的目的，是让手机横屏也能直接切换文稿。
- 大纲详情改用右侧栏，宽度最多 380 px、最多占视口的 46%；关闭按钮和保存 / 删除操作固定，表单独立滚动。竖屏继续使用底部详情。
- 地图整理把页签与关闭放在同一行，预览 / 应用固定在底部；中间参数独立滚动。箭头、元素与地图信息使用同样的紧凑侧栏，避免按钮被画布边界裁掉。
- 横屏规划面板编辑遇到覆盖式软键盘时，暂时收起导航和通用底栏，优先使用可见区域展示当前表单与操作。高度被系统缩小到 320 px 以下的 WebView 采用聚焦检测；失去焦点或关闭面板后恢复。下拉选项按可见高度计算位置。
- 设置窗口接近填满可见高度，分类在左、内容在右，分别滚动；确认和取消固定在底部。术语库缩减上下留白，不裁剪内容。

## PC

- 侧栏宽度随窗口调整，在 320–420 px 之间；大纲的关闭与保存区固定，保持可滚动正文和画布的空间。
- 设置窗口居中，最多 920×720 px，在较矮窗口中缩小高度，分类和选项各自滚动。
- 规划文件的底部操作区留出完整高度，避免图标及点击区域被状态栏裁剪。工具栏、更多菜单、插件区域和键盘接口继续有效。
- 布局变化不修改节点坐标、地图内容或正在编辑的工具参数；鼠标、滚轮、键盘与缩放窗口均可使用。
- 顶部导航统一按钮尺寸和分组留白。大纲 / 关系切换在 PC 上限制为紧凑分组；地图工具集中靠左，并显示图标和文字，更多菜单仍从右上角展开。窄屏保留等距图标及完整点击区域，选中背景收紧，避免被拉伸成大块色带。工具栏插件插槽和自动收纳逻辑继续有效。

## 验证

| 环境 | 视口 / 目标窗口 |
| --- | --- |
| Android 样式横屏，浅色 | 844×390、740×360 |
| HarmonyOS 样式横屏，深色 | 844×390 |
| 浏览器 PC 小窗口、宽屏 | 1024×600、1920×1080 |
| 实际 Windows Electron | 目标 1280×720、1024×600、1920×1080 |
| 切换与缩放 | 手机横屏→竖屏→横屏；Electron 打开工具时缩到 1000×500 再还原 |

Windows 的系统缩放会把上述目标取整为 1281×722、1025×602、1921×1082；测试容许最多 3 px 的系统取整，同时检查实际按钮、面板和内容边界。

`landscape-browser` 与 `landscape-windows-browser` 均纳入 verify，验证地图、箭头下拉、边界预览与应用、大纲及关系编辑、术语库、文件侧栏、新建文件、设置、阅读和缩放后的参数保留。手机浏览器另外模拟 240 px 可见高度的覆盖式键盘，检查表单操作与选择菜单不进入键盘区域。

截图和原始视口记录位于忽略的 `test-results/landscape/`。Windows 使用实际 Electron、隔离的临时工作区及原生文件保存；手机部分为浏览器仿真，不能替代鸿蒙 / Android 真机的旋转、键盘和触摸验收。

顶部工具栏样式调整后，2026-10-17 再次运行 `npm run verify -- --jobs 8 --windows`：52 项检查全部通过，342 个单元测试通过，耗时 186.6 秒。实际 Windows 截图已更新；本次仅修改 CSS，主包和功能分包大小不变。
