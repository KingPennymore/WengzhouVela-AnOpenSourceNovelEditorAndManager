# 术语库

文舟支持 `.gly` 和 `.glossary` 两种后缀。术语库与文稿一样保存在内部文件夹，可以导入、导出、重命名、同步 GitHub；它不列入阅读书库。

## 关联多个术语库

打开工作区 `.vela`，在“编辑 → 术语库文件”中，每行填写一个相对于该配置文件的路径。例如：

```json
"editor": {
  "glossaries": ["人物.gly", "资料/地点.glossary", "资料/设定.gly"]
}
```

可以在全局 `.global.vela` 设置默认术语库，其路径相对于内部文件夹根目录。作品或单文件的 `editor.glossaries` 会覆盖继承的清单。图形界面留空表示继承，填写 `[]` 表示停用。

## 维护词条

打开术语库文件默认显示图形界面，可搜索、新增、修改、删除词条，并填写分类、别名及释义。点击“保存术语库”才将修改写入文件。切换“源码”可以直接编辑 JSON；非法内容会显示错误并保留原文。

```json
{
  "version": 1,
  "name": "航程术语",
  "entries": [
    {
      "id": "character-linzhou",
      "term": "林舟",
      "category": "人物",
      "aliases": ["舟", "船长"],
      "definition": "负责记录航海日志。"
    }
  ]
}
```

词条 ID 可省略，保存时自动生成；已有 ID 和未知附加字段会保留。同一库内不允许重复词条，英文重复检查忽略大小写。每库最多 5,000 条、1 MB，每个词条最多 120 字符，释义最多 4,000 字符。

## 快速添加与补全

在编辑器中选中文字，按 **Ctrl+Alt+G**，或点击“选中词加入术语库”（窄屏放在“更多操作”中）。选择已有库或新建库，确认后自动关联到当前作品 `.vela`；缺少作品配置时会创建配置。

自动补全优先显示术语词条，旁边显示来源库名，详情显示完整路径及释义。中文输入一个字即可触发；也可以按 Ctrl+Space。别名补全会插入标准词条。同一词条存在于多个库时合并候选、别名和来源，按配置清单顺序展示释义。

候选词为 12px，来源文字为 11px，不随正文字号缩放。确认补全使用 Enter，Tab 保持正文缩进。

移动或重命名术语库会同步更新 `.vela` 中的引用。删除库后清单保留原路径，恢复文件即可重新生效。只拉取阅读清单时，已关联的术语库也作为配置依赖一并拉取。
