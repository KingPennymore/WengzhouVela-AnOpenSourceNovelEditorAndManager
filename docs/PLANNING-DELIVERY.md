## 设计决定与限制

- 按用户开发过程中的更新要求，正文编辑后直接改写大纲锚点，与正文一起自动保存；取消最初“只在内存更新、保存大纲才写回”的实现。定位不唯一时保留原引用并写 needsReview，不猜测位置。未提交的节点详情输入另存本机草稿，避免切换文件或重启丢失。
- 引用路径统一相对工作区根目录。文件操作和插件事务会先读取未载入的规划文件，并把改写作为实际文件变更提交。非法规划文件原文保留，不尝试用不可靠的解析结果覆盖它；这类文件中的路径须先修复源码才能可靠改写。
- 城市辖区只在已绘制的非水域格上扩展；城墙使用局部法向外扩和角切近似，未实现复杂凹多边形布尔裁剪。海岸线平滑 / 位移限制在格边邻域。结果超过 150000 点会拒绝生成并保留原图。
- PNG 最长边 8192 px、最多 3200 万像素，超大地图等比缩小；SVG 保留全图矢量。格式额外限定格子坐标绝对值不超过 1000000、箭头粗细 0.5–40、符号缩放大于 0 且不超过 20，以免异常参数使视图失效；未知字段仍原样保留。
- 默认状态和调色板由配置继承，新建文件采用生效的默认视图与格子尺寸。高级区保留 JSON 编辑入口，避免过早固定复杂配置表单。
- 已提供规划格式解析 / 序列化、插件符号注册、插件边界算法注册接口；带命名空间和停用清理，结果经过格式校验、预览确认和撤销流程。详见 [PLANNING-PLUGINS.md](PLANNING-PLUGINS.md)。
- 建议增强中的大纲字数汇总、状态 / 标签筛选、Markdown / OPML 导出、阅读页旁标题，以及可选的地图链接 # 锚点未包含在本次基础实现中。
