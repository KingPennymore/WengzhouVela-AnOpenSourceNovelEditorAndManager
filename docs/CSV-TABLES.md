# CSV / TSV 与 TXT 内嵌表格

CSV、TSV 默认以表格打开，源码模式仍可直接编辑原始文本。编辑页是可选中单元格的画布网格，阅读页是只读滚动表格，TXT 内嵌表格是静态 HTML；三者共用同一套列名、行号与配色。

## 编辑表格

表格只把屏幕内及缓冲区中的行列放进 DOM，滚动、缩放和拖动都不随文件变大而增加节点。表头、行号和单元格在同一画布上，整张表一起平移和缩放；横向平移到行号列离开视口时，左侧会保留一行不参与横向滚动的行号提示，避免失去行定位。

- 第一次打开：表格比屏幕窄时按 100% 靠左上显示；比屏幕宽时先适应宽度。
- 缩放范围 25%–300%。缩放低于 50% 时切换为 canvas 概览：空单元格与有内容的单元格用不同深浅色块，只保留行号和列名；在概览中点击以该点为中心回到 100%。
- 表格超出屏幕时右下角出现小地图，点击跳转。
- 首行可作为表头。表头状态保存在文稿元数据中，不写进 CSV 正文；列宽、缩放和滚动位置只保存在本机视图状态。行号按表格内可见行从 1 开始，不受“首行为表头”影响；概览中也会绘制行号。
- 普通滚轮平移，Shift+滚轮横向平移，Ctrl+滚轮或触控板捏合缩放；按住空格或中键拖动平移。单指始终用于平移，双指捏合缩放。
- 拖出可用范围时平移会停在边界，表格始终留在可见范围内；系统开启“减少动态效果”时直接归位。
- 列宽可拖动表头右边缘调整，调整距离按当前缩放换算。

CSV 的逗号、分号、Tab、引号和换行按标准转义。切换分隔符只改变显示方式，不改写单元格内容；`sep=` 行、UTF-8 BOM、CRLF/LF、末尾换行和原有引号在编辑后保持不变。

### 选择与编辑

单元格平时是普通文字，整张表只有一个浮层编辑框。先选中、再编辑：

| 动作 | 触屏（鸿蒙 / 安卓） | 鼠标 / 触控板（Windows） |
| --- | --- | --- |
| 平移 | 单指拖动（表头、行号或单元格空白处） | 拖动表头、行号或空白边距；按住空格或中键拖动；触控板双指滑动 |
| 缩放 | 双指捏合（以两指中点为中心） | Ctrl+滚轮、触控板捏合（以光标为中心） |
| 上下 / 左右浏览 | 单指拖动 | 滚轮上下，Shift+滚轮左右 |
| 选中单元格 | 单击 | 单击 |
| 选择区域 | 长按后拖动；拖选区角手柄 | 在单元格上拖动；Shift+单击 |
| 编辑 | 双击，或底栏“编辑” | 双击、Enter、F2，或直接打字 |
| 适应全表 / 100% | 底栏按钮 | Shift+1 / Ctrl+0，Ctrl+= / Ctrl+- 放大缩小 |
| 菜单 | 长按单元格 | 右键单元格、行号或列名 |

编辑框盖在单元格上并跟随缩放和平移，字号随缩放变化但最小 14 px。缩放低于 75% 或使用触屏时改用底部编辑栏。输入法组字期间不提交，也不响应单指平移。

键盘操作：方向键跳格；Tab / Shift+Tab 前进后退；Enter / Shift+Enter 在未编辑时下移 / 上移；Enter 进入编辑，编辑中 Enter 提交，Shift+Enter 换行；F2 进入编辑；Esc 取消；Delete / Backspace 清空选区；Ctrl+C / X / V 复制、剪切、粘贴区域（制表符分隔，支持单元格内换行）；Ctrl+Z / Ctrl+Shift+Z 走文稿的撤销和重做；Ctrl+A 选择全部；Ctrl+F 查找。

右键或长按菜单提供：在上方 / 下方插入行，删除行，上移 / 下移行；在左侧 / 右侧插入列，删除列，左移 / 右移列；清空选区；编辑；按列升序 / 降序。排序分“仅显示”和“写入文件”两种，写入文件后仍可用撤销恢复。菜单不会把首行表头移动到表头之外。

### 查找、筛选与状态栏

Ctrl+F 或工具栏“查找”打开表内查找。输入时选中第一处命中，Enter 跳到下一处；勾选“筛选行”只显示包含查询文本的行，不改变文件。

状态栏显示当前单元格（如 B12）、选中单元格数量、总行数和总列数；选区包含数字时显示合计与平均。表格不提供公式，也不保存另一份单元格数据。

单文件最多 8 MB、200,000 个单元格。解析错误会指出行列位置，并提供“在源码中定位”；整张表不会因为一处引号错误而只剩一句报错。

## 阅读页

阅读页使用同一网格的只读模式：原生滚动、只渲染可见区域，不可编辑，也没有缩放画布。表头与行号随表格滚动，滚动位置在再次打开时恢复，书签和阅读位置同时记录行、列滚动偏移。TXT 的翻页滑动排除规则仍会避开表格区域。

## 在 TXT 中插入

启用 TXT 格式工具后，使用表格图标或“插入 CSV 表格…”命令：

1. 选择工作区中的已有 CSV / TSV；也可创建新文件，填写相对路径、行数和列数。
2. 可填写标题，并选择第一行是否作为表头。
3. 表格出现在光标所在段落之后。新建文件保存在工作区，表格引用保存在所属作品 `.vela` 中，TXT 正文不变。

在编辑器中点击嵌入表格的“表格设置”，可更换引用、修改标题/表头、打开原表格，或移除嵌入。
移除嵌入不会删除原表格文件。原文件更新后，重新打开 TXT、预览或阅读即可看到最新内容。
源文件不存在或无法解析时显示明确的缺失提示，可以在设置中重新选择文件。

嵌入预览保持静态 HTML，最多显示 100 行、20 列，超出时说明显示范围；不做缩放，完整数据在原表格中编辑。表格宽度跟随正文栏宽，不超出页面，列宽按可用宽度分配；表内字号不继承正文字号，而是按栏宽和列数在 8–16 px 之间自动调整。表格高度随内容增长，不在表内单独滚动，正文页面仍可正常上下滑动。

## 保存、移动与导出

格式条目使用 `inserts` 中的 `csv-table` 类型，保留按行定位、撤销、外部改稿重定位和 Git 同步能力：

```json
{"type":"csv-table","src":"../资料/人物.csv","caption":"人物表","header":true,"at":[3],"hash":"01234567","head":"正文段落。"}
```

`src` 相对于 TXT 所在文件夹，可引用工作区内其他文件夹，但不能越过工作区或引用网络 URL。
移动、重命名表格或 TXT 时更新引用；复制作品时指向副本里的表格，复制单独 TXT 时继续关联原表格。
删除源表格时保留引用，恢复原文件后可以重新显示。局部仓库拉取会从 `.vela` 格式记录中识别所需 CSV/TSV 依赖。

编辑只替换受影响的源码片段：改动一个单元格只重写该字段，插入 / 删除行只改那几行，插入 / 删除 / 移动列和粘贴区域合并成一次事务。BOM、CRLF、`sep=` 行、末尾换行和未被改动的引号都原样保留。GitHub / Gitee / Gitea 的拉取与提交按原文传输 CSV/TSV，不再经过 `normalizeText`。

浏览器的文件导入、拖入和远端拉取会保留 UTF-8 BOM。Windows、鸿蒙和安卓的原生工作区扫描目前使用通用文本解码，读盘时会去掉开头的 BOM；在这些外壳上重新打开文件后，BOM 不会保留。CSV 的 CRLF 不受影响。若需要三端原生落盘也保留 BOM，需要原生文件层按 CSV/TSV 扩展名保留 BOM，属于后续改动。

TXT 导出仍为纯文字。HTML、Markdown、EPUB 导出将引用解析为当前表格的静态快照，不依赖工作区文件路径。
无法读取的表格在导出中显示缺失说明，并汇总提示；数据只作为文字处理，不执行公式或 HTML。

阅读表格放在 Shadow DOM 内，表格文字不进入 TXT 的 `textContent`、字数和书签/搜索偏移。

验证入口：`node --test tests/csv-tables.test.mjs`、`node tests/csv-tables-browser.mjs`、`tests/studio-browser.mjs` 的阅读页检查，以及 `tests/features-browser.mjs`、`tests/workspace-browser.mjs` 的回归。Windows 和安卓的实际外壳另用 `tests/csv-tables-windows.mjs` 与 `tests/android-browser.mjs` 验证。
