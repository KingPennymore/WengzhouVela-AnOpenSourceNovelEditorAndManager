文舟操作指南 · Vela 0.9.9
========================

文舟（Vela）是一款用于小说写作、资料整理和阅读的开源应用，支持鸿蒙、安卓和 Windows。

这份指南是普通 Markdown 文件，可以编辑，也可以点击标签栏右侧的“眼睛”阅读排版后的版本。你修改过的指南不会被升级覆盖。下表中的图片直接取自应用图标，图片旁注明名称，按住按钮或将鼠标停在上面也可查看名称。

## 先写第一章

1. 点击文件夹图标打开文件侧栏，点击带加号的纸张新建文件，选择“纯文本”或“Markdown 文稿”。新建和移动时直接选择文件夹即可。
2. 输入“第一章 启航”，下一行开始正文。文舟会识别章节，并自动保存到本机。
3. 点击顶栏的目录图标查看章节、字数与所在位置。点击底栏软盘可立即保存。
4. 需要换设备时，导出备份或使用 GitHub / Gitee 同步。轻量版需要的阅读与排版组件可在“插件与组件”中下载。

## 术语库 GLY

术语库可记录人名、地名、设定、分类、别名和释义。列表中的放大镜搜索词条，分类下拉框筛选，加号新建；点击词条编辑，长按复制名称。词条内的返回箭头回到列表，复制按钮复制词语，回收站删除词条并要求确认。改动自动保存。

在作品设置中选择使用的术语库，可在正文获得词条补全、高亮与释义，也可以开启正文旁的术语库面板。关系节点现在链接到术语库的具体词条；词条改名后，链接仍按其身份定位。

大纲节点直接显示标题、概要和详情预览，三部分用分隔线区分；较长详情在面板中完整查看。点击节点编辑标题、概要、Markdown 详情、状态、标签与颜色，再点同一节点可收起面板。大纲节点可选择父节点；Enter 新建同级，Ctrl / Command+Enter 新建子节点，Tab 缩进，Shift+Tab 反缩进。拖动只改变当前节点位置。关系中直接连接越多，节点越大。

点击连线可以选择无方向、起点到终点、终点到起点或双向，修改短标签与 Markdown 描述；删除连线不会删除两个端点。父子连线删除后，子节点移回顶层。

大纲节点连接正文锚点；长按或右键选择“跳转到正文”。关系节点在详情中选择“链接到术语库词条”，指定术语库与词条，长按或右键可跳到词条。多条链接时先选择目标。已有的旧正文链接会保留在“旧正文锚点”中。正文编辑后会直接更新锚点文件，定位不明确的链接列为待确认。

### 完成箭头

选择箭头工具后，依次点按绘制点形成路径。手机双击地图即可完成，电脑使用右键，也可点击侧栏的“完成箭头”；至少需要两个路径点。右上角会显示手势提示。完成后退出箭头工具，继续点按不会开始另一条箭头；要再画一条，重新选择箭头工具。

侧栏可以撤回最后一个路径点或清空路径。窄屏可关闭侧栏使用完整画布，再从原按钮打开；未完成路径保留。选择已有箭头可修改、反转方向或删除。元素能自由放置，也可吸附到格心。 用底栏光标选中元素后，拖动选中框的角点等比缩放，拖动圆形手柄旋转，也可先按住元素、再用双指旋转和缩放；这不会改变地图缩放。整次手势可用一次撤销恢复。窄屏选中后先保留画布，宽屏同时打开设置。

![元素设置](vela-guide-icons/settings.svg) **元素设置**：窄屏选中元素后，从右侧滑出的齿轮按钮位于地图详情上方，点按编辑，重复点按收起。

![旋转手柄](vela-guide-icons/range.svg) **旋转手柄**：拖动框顶圆形手柄旋转；聚焦手柄后可用方向键微调。

### 浏览、边界与导出

信息点名称显示在点下方。浏览时点击带地图链接的信息点，先从下方查看目标简介，再选择是否跳转；返回按钮回到上一张地图。拖动平移，滚轮或双指缩放。

更多菜单中可打开“显示六边形网格”，便于对齐位置；它随地图保存，不改变绘制点，缩得很小时会自动隐去密集格线。

隐藏绘制点只改变显示，边界、信息点、箭头与元素继续显示，点数据不会删除，重新显示后可继续绘制。边界工具从右侧面板调整参数，先预览，再应用；同一结果可重新生成，支持撤销。PNG 为图片，SVG 为矢量文件，导出会保留地图内容。

![精简绘制点](vela-guide-icons/simplify.svg) **精简绘制点**：点击底栏的地图整理按钮，选择“精简绘制点 → 预览”，查看精简前后的数量，再确认“应用精简”。只删除不影响现有边界和填充的点，带信息、被箭头引用和旧地形点会保留；应用后可撤销。

**独立地形**：在“地图整理 → 独立地形 → 预览”中，将当前封闭的填充区域转换为一个可操作的矢量元素。形状与颜色保留，已转换区域的普通绘制点会移除；未封闭点、信息点、箭头引用和附加信息保留。预览显示移除数量与转换前后的保存大小，复杂轮廓可能增大文件。确认“转换地形”后，用选择工具点按区域可设置名称、位置、颜色和不透明度，拖动区域可移动，设置面板可以删除地形。转换、移动、改色和删除均可撤销；保存并关闭后，原始普通绘制点不再存入文件。后续绘制产生新的填充，不会重建或覆盖独立地形。地图文字保留主题或原有阵营颜色，并增加反差描边，避免与地形颜色接近时难以辨认。


下拉选择栏、箭头或元素侧栏、范围设置和地图详情，再点一次原按钮都会收起。侧栏滑动不会触发沿途按钮；滑动从选择栏开始时也能滚动。

关系页使用圆形人物节点与弧线，连接多的节点更大；一键整理按人物群组排成环。大纲继续使用矩形情节卡片和层级连线。

地图左上角悬浮的返回箭头逐张返回来源地图，不占工具栏。元素侧栏可按“部队 / 军事设施 / 自然地形 / 建筑 / 事件 / 我的图片 / 插件元素”筛选；“我的图片 → 导入图片”接受静态 PNG、JPEG、WebP，原图最多 20 MB、1600 万像素，会自动缩到长边 1024 像素以内、单张 256 KB 以内。导入后点地图放置，用光标工具选择并调整旋转、大小；撤回可取消导入或放置。图片随地图保存。

下拉选项和颜色在文舟内部显示；长列表可搜索，电脑支持方向键、Enter 和 Escape。导入文件时仍由系统文件选择器取得文件访问权限。

## 作品设置 VELA

作品设置管理名称、章节规则、阅读排版、书单、术语库和不同文件类型的默认值。全局设置用于个人偏好，作品设置用于作品推荐，单文件设置用于例外。列表或页面按钮在基础设置、TXT 格式和高级配置间切换；软盘保存，源码按钮修复 JSON。无效配置不会覆盖原文。

## 仓库、订阅和备份

仓库页的返回箭头回到写作；加号连接或创建仓库，刷新重新读取，文件夹浏览目录，差异查看本地与远端内容，提交上传选中的修改，拉取读取远端。发生冲突先查看两边内容，再选择合并结果。令牌与授权在设置中管理。

订阅页的加号添加来源，刷新检查更新，红点或数字提示新内容，点击条目阅读或导入，三个点管理来源。订阅不会替你修改正文。

设置中的“导出全部文稿备份”“恢复文稿备份”用于保存和恢复本机资料。卸载或清空应用数据会删除内部文件，建议定期备份。隐私协议与源码：[文舟项目](https://github.com/KingPennymore/WengzhouVela-AnOpenSourceNovelEditorAndManager)。

## 阅读、电子书与 LaTeX

阅读页的书本卡片打开文稿；加号或导入按钮添加书籍；目录选择章节，书签保存位置，进度条跳转，A / 字号调整文字，版式按钮选择滚动、翻页或双页，左右箭头翻页，返回箭头回书库。长按文字可复制、搜索或使用词条功能。EPUB 等格式需要的组件在插件页安装。

LaTeX 标签的源码按钮编辑，眼睛打开 PDF 预览。播放或编译按钮开始本地排版，停止取消，问题列表跳到错误位置，定位按钮在正文与 PDF 间跳转，导出按钮保存 PDF。轻量版先安装排版组件，完整版内置；编译不会上传源码。

## 插件、外观和 Windows

插件页的四方块进入管理，加号或 ZIP 安装本地插件，下载箭头安装在线组件，环形箭头检查更新，开关启停，回收站卸载。插件可以添加工具栏、侧栏、底栏和选区菜单动作。

设置中可选简体中文或 English、跟随系统或固定深浅色、自定义配色与字号。减少动态效果跟随系统设置。Windows 使用同一套界面，F11 切换全屏；窗口大小与位置会被记住。

## 横屏与 PC 窗口

横屏手机保留文件标签，方便切换文稿。大纲详情在右侧打开，关闭和保存按钮固定在面板上下，内容单独滚动；地图工具和地图整理的操作按钮同样固定在底部。空间不足时滚动查看参数，不必关闭面板寻找保存按钮。

PC 端根据窗口宽度调整侧栏，设置窗口居中显示，分类与选项分别滚动。改变窗口大小会重新调整画布与面板，支持鼠标、滚轮和键盘操作。横屏软键盘占用空间时，正在编辑的规划面板优先使用可见区域；关闭编辑或键盘后恢复工具栏。
