首轮构建与测试同时运行时，同步测试曾遇到启动资源 404；构建结束后重跑已通过。历史原始日志保存在 `test-results/verify-first/` 和 `test-results/verify-second/`，不改写失败记录。最终统一回归另存于 `test-results/verify/`。

最终结果：`npm run verify -- --jobs 6` 整轮通过，耗时 206.4 秒；核心静态检查、前端构建及两项资源/版本完整性检查通过，77 组回归通过（76 组浏览器检查 + 509 项单元测试），无失败、无跳过。`git diff --check` 通过。
