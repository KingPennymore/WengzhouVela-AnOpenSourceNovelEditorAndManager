# 0.9.9.1 登录、同步、术语提示、输入法与选择控件修复

日期：2026-10-19。基于主线提交 `992ea8c`，版本号继续使用 0.9.9.1。

## 问题与处理

1. **令牌重复登录与缓存。** 三个平台原本每次登录均重写凭据，现改为远端 `/user` 验证成功后，已保存的同一令牌直接复用。鸿蒙还存在两个异步竞态：较慢的旧查询可能把登录后的新缓存改回空值；尚未结束的安全资产写入可能在退出后恢复令牌。已保护较新的缓存，并将凭据写入和移除串行处理。延迟查询、延迟写入的模拟测试覆盖这两种情况。浏览器端区分格式、401、403 和其他 HTTP 错误。没有取消远端验证，也没有将令牌写入文稿。
2. **`.vela` 导致同步被阻止。** 阅读位置会自动写入 `positions`，旧逻辑比较整个字符串，把位置与排版序列化变化视作编辑冲突。新逻辑仅对有效的作品/全局配置使用忽略位置的内容比较；拉取保留本机位置，预览后仅位置变化不使预览失效。提交列表在有匹配共同版本时不默认选择位置变化。不同配置字段可三方合并，同一字段的冲突、删除与修改冲突、同一文稿格式记录的并发修改继续要求选择。写入内容与远端原始共同版本分别保存，合并后仍可正确识别本地修改。远端分支推进的 409 保护和普通文稿全文变化保护继续生效，未使用强制覆盖。
3. **深色术语释义背景。** CodeMirror 默认 tooltip 是未分层的浅色主题，术语提示原本只有尺寸和排版规则。现在背景、文字、边框和箭头统一使用应用的 `--paper`、`--text`、`--line`，覆盖编辑器默认颜色。
4. **中文输入法补全。** Chromium 的 IME 测试复现了组合拼音时出现英文补全；原有补全结果的 `validFor` 同时接受拉丁字母和汉字，可能保留拼音阶段的候选。现在所有补全源在组合期间停用，组合开始清理候选、结束后等待最终编辑落入状态再查询；正文名词索引不发送预编辑拼音。异步索引等待所有待处理块完成，避免首批结果未包含远处名词时过早返回。测试覆盖术语候选、正文名词、接受补全，以及九万余字正文的末批名词。
5. **圆点选择控件。** 原生 checkbox 保留类型、标签关联、键盘和多选语义，统一显示为空心圆、选中时填充主题强调色。保留禁用、焦点和部分选中状态。Markdown 任务状态也改为对应圆形标识，保留完成/未完成的可访问名称。
