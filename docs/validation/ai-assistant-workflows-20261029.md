# AI 整理与续写实现验证（2026-10-29）

分支：`feature/ai-assistant`，承接 `220c8f4` 及此前阶段 1 的原生桥接实现。

## 实现

移除 AI 按钮下方 56px 顶部区域，正文以透明右侧间距避开按钮。未启用或隐藏 AI 按钮时不改变正文间距。

按 ADR 0009 分离入口、整理视图、请求计划、纯格式转换、工作区事务适配与 CodeMirror 续写扩展。`ProjectService.bindBuiltin` 是应用宿主内部接口，不向插件暴露；复用现有事务队列、编辑锁、修订检查、后端原子落盘与恢复。内置会话停止时清理临时绑定及观察缓存。

整理覆盖章节选择、发送确认、上下文预算分批、进度取消、无效项过滤、名称/别名去重、可编辑预览、`.gly` / `.pcs` / `.vlmp` 转换、作品术语库关联和整体撤销。模型路径/ID 不参与文件操作；预览后的目标变化与撤销前的后续编辑均拒绝覆盖。地图只生成信息点，近似位置标明参考，点间互链可在地图中跳转。

续写默认关闭、按作品记录。只发送光标前最多 2000 字与本章标题，淡色装饰不进入文稿；部分输入保留剩余建议，Tab/点按或 Ctrl+→ 接受，Esc/按钮拒绝，接受后的文字可撤销。输入法组合、补全弹窗、只读、预览、项目锁定和失焦时停用或取消；同位置去重、每分钟限频、失败退避，统一请求通道检查同意、服务绑定、取消与本地日期的每日上限。

## 边界

本次验证使用模拟服务，没有向真实 AI 服务发送文稿，也未使用真机输入法。额外附加术语/大纲上下文仍未接入；流式、总结、改写、插件授权属于后续阶段。没有重新生成或签署安装包，上一轮签名的安装包不含本次新功能；发布前须重新构建与签名。
