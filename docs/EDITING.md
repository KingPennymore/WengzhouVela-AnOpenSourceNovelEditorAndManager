# 文档编辑

0.8.0 使用 CodeMirror 6，按文件保留编辑选区与撤销状态；最近八个编辑状态驻留，超过后释放以限制内存。本地持久历史不依赖编辑器驻留。

## 创作工具

顶栏命令按钮可搜索并执行：章节管理、工作区搜索替换、词库与片段、书签批注与待修改标记、本地历史恢复、源码预览并排。底部八个常用操作及原有快捷键保持可用。

章节改名校验自动识别规则；移动章节连同正文移动，保持换行边界；删除包含该章正文。重要操作先保存本地快照，当前编辑器也可撤销。章节目录分批显示、可以筛选；行号、字数和章节位置随编辑增量更新。IME 合成期间 Tab 不插入缩进。

`Ctrl+F` 打开与主题一致的查找与替换面板，支持上一处/下一处、当前替换/全部替换、区分大小写、全词及正则表达式；中文模式使用中文文案，非法正则会明确提示。

`Ctrl+Shift+F` 搜索当前文稿、当前工作区或所有内部文本。大小写可选，文字作为字面内容搜索，不解释成正则。结果最多 1000 项；关闭可取消。替换先展示逐文件对照，预览之后文稿发生变化则拒绝执行，避免覆盖新修改。替换前保留各文件历史。

词库每行一个名称，最多 1000 项；片段每行 `名称 | 内容`，用 `\n` 表示换行，最多 100 项。它们加入动态补全，结合语言、当前文稿和插件候选。`Ctrl+Space` 唤起，Enter 确认，Escape 关闭。Tab 默认插入两个全角空格；代码模式或配置普通空格缩进时按 `indentSize` 插入，Shift+Tab 取消行首缩进。

`Ctrl+Alt+B` 添加编辑书签；标记页可给当前选区添加批注或待修改内容。未被修改的锚点随插入/删除移动；原位置被改写、跨格式或者匹配不唯一时标记为待确认，避免跳到错误文字。标记以文档 ID 保存，重命名后仍可访问。

## 选区与浮层

拖选、Shift 扩选、双击/三击、手机长按手柄和多范围选区共用一套行为：拖动或按住指针期间不弹出术语释义，也不显示选区菜单；选区变化时旧菜单立即隐藏，选区停止变化约 0.2 秒后在新位置出现（位置规则见下文“选中文字后的菜单”）。选区收起或输入替换选区时立即隐藏；按 Escape 或执行操作后，同一选区不再自动弹出，直到下一次点按、按键或系统菜单请求。

术语释义只在没有选区时悬停出现，位置避开光标所在行（光标在术语下方时向上弹出），过长的释义在浮层内滚动。选区变化不再重建术语高亮，也不再让界面翻译重新扫描整页；长选区的“选中 N 字”在选区稳定后统计。回归测试：`node tests/selection-browser.mjs`（直接使用源码，不需要先构建）。

## 保存与恢复

自动保存有延迟，手动保存立即执行。保存确认对应修订号，新输入不会被旧保存结果清除为已保存。原生文件服务提供临时写入、事务回滚和启动恢复；失败保留当前编辑内容和未保存状态。恢复历史先显示差异，再写回编辑器。

单文件最多十个历史快照，单文件历史预算约 4M 字符、全工作区约 8M 字符，旧快照优先释放；一个超大快照也受全局预算约束。浏览器预览遇到存储配额不足时先释放历史再尝试保存当前文稿，仍失败会报错。正式应用使用原生内部文件服务。本地历史是恢复辅助，不能替代导出备份。

## 格式

TXT 适合整部小说；可在命令面板开启“TXT 格式工具”，为 TXT 加粗体、着重号、注音、居中、右对齐、插图和命名样式（如“系统提示”“书信”，可在“管理样式…”中自定义）。样式可用于整段，也可只用于选中的字；“清除格式”去掉选区和所在段落的格式。格式保存在作品配置 `.vela` 中（打开 `.vela` 的“TXT 格式”页可查看），TXT 本身仍是纯文字，复制到平台不用清洗。阅读页显示同样的格式；“导出章节”可选 TXT、Markdown 或 HTML，复制 HTML 时会带上格式；“导出 EPUB…”生成带目录、格式和可选封面的电子书，书名、作者、简介取自作品配置。在文舟外改过正文后，格式会按原文自动重新定位，找不到的进入“格式待确认”，不会丢弃，详见 [VELA-V3-DESIGN.md](VELA-V3-DESIGN.md)。Markdown 有格式工具和安全预览，代码块支持语言高亮；CSV / TSV 使用可缩放、可拖动的画布表格，表头、行号和单元格一起平移缩放，平移限制在可见范围内；先选中再编辑，支持区域选择、制表符复制粘贴、增删移动行列、两种排序（只改显示或写入文件）和表内查找。编辑只替换受影响的源码片段，保留 BOM、CRLF、`sep=`、末尾换行和原有引号；阅读页是只读滚动表格。TXT 内嵌表格宽度适应正文栏宽，高度随内容增长，字号独立于正文并自动调整，表格上仍可上下滑动正文页面。HTML 嵌入预览使用原生 Web 组件，禁止文档脚本和外部联网；独立预览可显式启用本地脚本。常见源码格式按语言高亮与补全，代码预览只读，大于 200K 字符时省略预览高亮以避免主线程长任务。

宽度至少 1000 CSS px 时可开启源码与预览并排；窄屏使用切换。TXT 预览按阅读页的方式显示章节标题和格式；在 TXT 和 Markdown 预览中，章节目录、到顶 / 到底、章首 / 章尾的跳转直接滚动预览，不再切回源码。TXT 小说模式默认不显示行号，可在设置“编辑”中打开。LaTeX 的主文件/引擎由作品配置推荐，本地 PDF 编译、宏包插件和限制详见 [LATEX.md](LATEX.md)。PDF 作为只读阅读文件，不把二进制内容当作文本编辑。

## 选中文字后的菜单

选中文字后，文字上方出现一排按钮：剪切、复制、粘贴（只读内容只有复制），最右侧“更多”收起其余操作：搜索、加入术语库、插件添加的操作，以及没有格式工具栏的文件（如 LaTeX）的格式命令。工具栏上已有的格式命令不重复出现。菜单在选区上方居中；选区开头已经滚出编辑区，或上方放不下时，菜单固定在编辑区工具栏下方。滚动时菜单暂时隐藏，停止滚动后按新位置重新出现。触屏上按钮高度为 44 px。

章节管理使用可搜索的章节列表，支持直接上移、下移、改名和确认删除；批注管理支持筛选、选择当前结果和批量删除。长列表分批加载，搜索保留输入框焦点。CSV 阅读页按完整表格查找，并以行列坐标定位与保存批注。
