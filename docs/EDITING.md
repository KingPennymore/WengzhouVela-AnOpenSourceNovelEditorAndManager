# 文档编辑

0.8.0 使用 CodeMirror 6，按文件保留编辑选区与撤销状态；最近八个编辑状态驻留，超过后释放以限制内存。本地持久历史不依赖编辑器驻留。

## 创作工具

顶栏命令按钮可搜索并执行：章节管理、工作区搜索替换、词库与片段、书签批注与待修改标记、本地历史恢复、源码预览并排。底部八个常用操作及原有快捷键保持可用。

章节改名校验自动识别规则；移动章节连同正文移动，保持换行边界；删除包含该章正文。重要操作先保存本地快照，当前编辑器也可撤销。章节目录分批显示、可以筛选；行号、字数和章节位置随编辑增量更新。IME 合成期间 Tab 不插入缩进。

`Ctrl+F` 打开与主题一致的查找与替换面板，支持上一处/下一处、当前替换/全部替换、区分大小写、全词及正则表达式；中文模式使用中文文案，非法正则会明确提示。

`Ctrl+Shift+F` 搜索当前文稿、当前工作区或所有内部文本。大小写可选，文字作为字面内容搜索，不解释成正则。结果最多 1000 项；关闭可取消。替换先展示逐文件对照，预览之后文稿发生变化则拒绝执行，避免覆盖新修改。替换前保留各文件历史。

词库每行一个名称，最多 1000 项；片段每行 `名称 | 内容`，用 `\n` 表示换行，最多 100 项。它们加入动态补全，结合语言、当前文稿和插件候选。`Ctrl+Space` 唤起，Enter 确认，Escape 关闭。Tab 默认插入两个全角空格；代码模式或配置普通空格缩进时按 `indentSize` 插入，Shift+Tab 取消行首缩进。

`Ctrl+Alt+B` 添加编辑书签；标记页可给当前选区添加批注或待修改内容。未被修改的锚点随插入/删除移动；原位置被改写、跨格式或者匹配不唯一时标记为待确认，避免跳到错误文字。标记以文档 ID 保存，重命名后仍可访问。

## 保存与恢复

自动保存有延迟，手动保存立即执行。保存确认对应修订号，新输入不会被旧保存结果清除为已保存。原生文件服务提供临时写入、事务回滚和启动恢复；失败保留当前编辑内容和未保存状态。恢复历史先显示差异，再写回编辑器。

单文件最多十个历史快照，单文件历史预算约 4M 字符、全工作区约 8M 字符，旧快照优先释放；一个超大快照也受全局预算约束。浏览器预览遇到存储配额不足时先释放历史再尝试保存当前文稿，仍失败会报错。正式应用使用原生内部文件服务。本地历史是恢复辅助，不能替代导出备份。

## 格式

TXT 适合整部小说；Markdown 有格式工具和安全预览，代码块支持语言高亮；CSV 支持表格编辑、行列分页、增删行列、排序和制表符区域粘贴。HTML 嵌入预览使用原生 Web 组件，禁止文档脚本和外部联网；独立预览可显式启用本地脚本。常见源码格式按语言高亮与补全，代码预览只读，大于 200K 字符时省略预览高亮以避免主线程长任务。

宽度至少 1000 CSS px 时可开启源码与预览并排；窄屏使用切换。LaTeX 的主文件/引擎由作品配置推荐，本地 PDF 编译、宏包插件和限制详见 [LATEX.md](LATEX.md)。PDF 作为只读阅读文件，不把二进制内容当作文本编辑。
