# 点绘地图

`.velamap` / `.vlmp` 为 version: 1 的 JSON 文件，kind 是 MAP。绘制点提供边界样本；信息点记录地点并链接地图，两者的用途独立。地图从空白开始，不再选择水域、平原、山地或城市等地形。

```json
{
  "version": 1,
  "name": "北境",
  "grid": { "orientation": "pointy", "size": 32 },
  "info": { "summary": "北方的城池", "detail": "", "fields": [] },
  "palette": "inherit",
  "drawing": { "distance": 3 },
  "cells": { "0,0": { "type": "draw" } },
  "markers": [{ "id": "m-1", "x": 140.5, "y": 88, "name": "白石城", "note": "", "link": "地图/白石城.vlmp" }],
  "arrows": [],
  "symbols": [],
  "generated": []
}
```

绘制点以轴坐标保存，界面画出点而不是填满六边形。首次放置后展示相邻识别圆，滑块可以调整范围，确认后写入 drawing.distance。圈的半径为 `sqrt(3) × grid.size × distance`，新文件默认 distance 为 3，允许 1–16；后续可用“相邻范围”按钮重设。信息点使用独立平面坐标，可以自由放置、取名、移动和链接，名称显示在点下方。

浏览支持拖动、滚轮、双指缩放与适应全图。点击信息点从下方或右侧弹出说明；带链接时先读取目标地图的名称与概要，用户点击“跳转到地图”后才导航。异步读取失败显示错误，不自动跳转；文件缺失、改名或移动按工作区引用改写规则处理。返回栈、面包屑、系统返回和 Alt+Left 保留。

原常驻地图信息栏已移除。右下角“显示详情”图标打开地图名称、概要、Markdown 详情、字段表及编辑表单。窄屏为底部弹层，宽屏为右侧浮层；Enter / Space 打开，Escape 或关闭按钮收起，aria-expanded 与焦点随之更新。弹层内部滚动，滚动容器透明，由外层绘制背景。原 infoPanel 字段保留，新的详情入口不再使用常驻侧栏或底栏。

绘制与删除支持连续拖动，选择工具移动信息点或符号；箭头和元素各保留一个入口，点击打开右侧设置栏，窄屏也从右侧展开。箭头的样式、颜色、粗细、弧度、标签、阵营、完成路径、撤回路径点和清空路径集中在同一栏；手机可双击地图完成，电脑使用右键，右上角显示提示。至少两个路径点，完成后退出箭头工具并恢复浏览，后续点按不会开始新箭头。双击识别仅在地图画布且箭头工具启用时运行，不延迟其他按钮。选择已有箭头可保存属性、反转或删除。窄屏可先关闭侧栏在完整地图上操作，再点原工具按钮继续设置或完成箭头，路径不会丢失。元素栏集中类型、外框、编制、标签、阵营、旋转、缩放、吸附设置，选择后可修改和删除。删除优先命中可见信息点，再按符号、箭头、生成边界、绘制点处理，可通过“只删除”限定绘制点、箭头或符号。顶部只有一行工具，溢出工具在编辑页右上角的纵向“更多操作”中；上方采用与格式工具一致的等距按钮，元素保留在顶栏；光标选择、适应全图、相邻范围、生成边界移至文舟原有底栏，与原快捷按钮等距。撤销重做只保留原有一组按钮。至少 100 步撤销重做，切换文件保留；重新启动以已保存数据为准。PNG / SVG 导出包含绘制点、信息点名称、边界、箭头与符号。PNG 最长边 8192 px、总像素最多 3200 万，超大地图等比缩小。

## 封闭区域自动填充

绘制点或相邻范围改变后，用同一距离规则检查各相连分组。至少三个非共线点，且相邻图形成环时，以该分组的外轮廓填满内部，不增加 cells。开放链和共线点不填充；独立的嵌套环通过 evenodd 填充规则可形成孔洞。此判定基于距离，所以过大的范围可能将本来分开的样本连在一起；首次绘制提示与“相邻范围”可调整。已有文件的明确范围保持不变，不静默改为新默认值。

填充保存在 generated 的固定 ID `g-drawing-fill` 图层；重新绘制或删除点替换该图层，其他生成层保持原样，与本次操作一起撤销或重做。保存时写回，重新打开保留；单纯打开旧文件时计算显示填充，不写文件；下一次实际编辑才一并保存。轮廓来自统一算法的 fillPaths 元数据，插件可以读取；不要复用该保留 ID。PNG 和 SVG 均包含填充。

“更多操作 → 隐藏绘制点 / 显示绘制点”仅改变当前文件的显示状态，切换地图后返回保留；不删除点，不改变边界计算或已保存的文件。信息点、生成边界、箭头和元素继续显示，PNG / SVG 仍导出完整数据。

预览加载使用代次校验并清理旧渲染器；底栏只挂载一个操作容器，地图链接往返、重复预览和窄宽屏迁移均不能累积重复工具。标签栏类型标识为 VLMP。

## 距离边界

统一算法处理每一组相邻样本及其轮廓，不判定哪条是海岸线、湖岸或河岸，也不按地形分类。步骤如下：

1. 以确定的轴坐标顺序读取绘制点，用空间桶寻找半径内的点对。
2. 对距离允许但不直接六邻接的点对，在线段上补临时采样格，形成连接。临时样本仅供计算，不写回 cells。
3. 收集连接区域的有向轮廓边，共享边相消；按端点串成闭环。内外轮廓使用同一流程。
4. 对轮廓连续经过的六边形段，用带种子的随机数选两个不相邻的顶点作为路径控制样本，不要求沿六个顶点逐一描边。孤立点用两个顶点和两个非顶点的辅助点形成闭合弧形。
5. 用插值曲线经过这些样本，按 smoothing 细分，并以 roughness 加入有界的中间起伏；同输入、同参数、同种子完全一致。结果的 anchors 元数据记录选取的顶点，便于复核。
6. 先预览，确认才将结果写入 generated。同一结果 ID 会替换旧结果，操作可撤销。

smoothing 是 0–4 整数，roughness 是 0–1，seed 是 32 位非负整数。相邻点对最多 2000000 项，临时采样格和最终路径各最多 150000 项，超限停止并保留原图。默认范围来自 `.vela` 的 formats.map.neighborDistance；文件 drawing.distance 优先。算法窗口临时修改参数只影响本次生成。

此算法生成的是采样区域的边界，稀疏线状样本会形成细长的闭合轮廓，适合表示河岸，不会自动推断河流中心线或真实地理结构。距离过大会连接本来分开的区域或缩小孔洞；轮廓插值是视觉近似，极窄通道与凹角应通过预览检查。算法不保证任意采样的曲线拓扑保持，不在后台自动覆盖已有边界。

## 旧文件与扩展

旧 fill、palette、generated、城市辖区和所有未知字段继续解析并保存；地形格在新版显示为绘制点，有名称或链接的旧格同时显示为信息点。旧海岸线和城市算法继续作为纯函数供原测试或插件调用，内置界面只提供新的距离算法，保存不会强制重新生成旧结果。

限制仍为 8 MiB、50000 个绘制格、2000 条箭头、5000 个符号，另有 5000 个自由信息点。cells 按 r、q 排序，JSON 固定键顺序、2 空格缩进、末尾换行。未知字段保留；解析失败保留原文并切换源码修复。信息点按 ID 参与结构化三方合并，路径改写覆盖 markers[].link 与旧 cells[].link。

代码分包、军事符号、边界算法和界面区域的插件接口见 [规划格式插件接口](PLANNING-PLUGINS.md)。
