# 地图文件

`.velamap` / `.vlmp` 是 version: 1 的 JSON 文件，kind 为 MAP。六边形采用轴坐标 `q,r`，支持 pointy / flat。格子按 r、q 排序写出，2 空格缩进并以换行结束。未知字段保留；非法文件只显示错误和原文，切换源码修复。上限为 8 MiB、50000 格、2000 条箭头、5000 个符号。

调色板使用 `.vela` 的 `formats.map`；文件中 `palette: "inherit"` 继承，也可写内联数组。颜色引用条目 ID，role 为 land / water / city / other。全局、作品、单文件逐级覆盖，数组整体替换。

浏览 / 平移支持拖动、滚轮和双指缩放；适应全图计算全图范围。绘制与删除支持连续拖动。删除按符号、箭头、生成边界、格子的顺序命中，可限定格子 / 箭头 / 符号。选择工具可拖动符号、修改旋转、缩放与属性。箭头先点已有格子，再点“完成箭头”或双击。元素位置独立于格子，可选择吸附格心。撤销与重做至少 100 步，切换文件保留会话历史；重新启动后以已保存文件为准。

底部标题栏点击或 Enter / Space 在收起和半屏间切换，从把手上拉可展开半屏或全屏，下拉收起。只有把手的手势控制信息区。`infoPanel: "side"` 在宽度至少 900 px 时采用右侧面板。展开后可编辑地图名称、概要、Markdown 详情与字段表。格子链接使用工作区根目录相对路径；地图间跳转保留返回栈，支持面包屑、系统返回和 Alt+Left。文件缺失时保留引用并标记失效。

PNG 与 SVG 导出完整地图，包含生成边界、箭头和符号；SVG 为代码绘制路径，不带脚本或外部图片。PNG 最长边限 8192 px、总像素限 3200 万，超大地图等比缩小。三端 PNG 导出单独校验 PNG 文件头，不借用 ODF 格式校验。

## 自动海岸线

1. 从调色板筛选 land / city 格，收集六边形六条有向边；两格的共享边相消。
2. 按端点串成闭环，外环与湖泊环方向相反。未绘制格等同外部水域。
3. 按 smoothing 做 Chaikin 角切平滑，再在每条短线中点加入带种子的法向位移。
4. 位移幅度最多为格子尺寸的 0.12 倍乘 roughness；角切及位移限制在原边邻域内，不跨过相邻格心。同种子和同输入完全确定，格子输入顺序不影响输出。

参数 smoothing 为 0–5 整数，roughness 为 0–1，seed 为 32 位无符号整数。预估结果超过 150000 点时拒绝生成，提示减小平滑次数或输入范围，防止超大结果覆盖有效文件。

## 自动城市边界

1. 按六邻接把 city 格聚类，使用聚类首个坐标构成稳定城市 ID；名称取城市格 name。
2. 对城市外轮廓按 wallPadding 外扩，生成角切圆角或棱堡锯齿城墙。
3. 所有城市同时出发，用优先队列执行多源 Dijkstra；关闭 weighted 时相当于 BFS。进入目标格的代价为地形 cost（默认 1），距离上限为 radius；同距取字典序更小的城市 ID。
4. 只遍历已绘制且非水域的格子。对各城市的归属区域分别取外轮廓并平滑，辖区以城市格颜色淡化后半透明填充。

圆角是多边形角切近似，不是精确圆弧；城墙是局部法向外扩近似，凹角和邻近城市的城墙可能接近或重叠，不执行复杂布尔裁剪。空格不参与辖区扩张。算法不会修改 cells，结果连同参数写入 generated；同 ID 重运行替换原结果，可撤销。参数默认值来自 `.vela`，对话框调整只对本次生成生效。
