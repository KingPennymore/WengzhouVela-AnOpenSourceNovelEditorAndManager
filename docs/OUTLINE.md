# 大纲文件

`.process` / `.pcs` 为 version: 1 的 JSON 文件，kind 是 OUTLINE。剧情树用 children 表达父子层级，关系图只用 edges 表达人物等对象之间的关系；树边不会出现在关系图中。共用 nodes，layout 保存平面坐标。最多 5000 个节点、10000 条关系边、4 MiB。

新文件为 `{version:1,name:"大纲",view:"tree",root:"",roots:[],nodes:{},edges:[]}`，没有强制存在的父节点。剧情树允许多个顶层节点，roots 记录其顺序；关系图可以添加任意独立节点，允许循环关系。children 仍不得循环或有多个父节点。旧 root 单根文件保持可读，不自动删除旧根或其内容；没有 roots 的旧文件从父子引用推导顶层节点。

打开后选择“剧情树”或“关系图”。树支持折叠、拖动排序与改变父节点；触屏使用节点旁的拖动把手，桌面也可直接拖动节点标题。节点获得焦点后 Enter 新建同级节点，Tab 缩进，Shift+Tab 反缩进，顶层节点也可缩进和重新移回顶层；方向键导航或展开折叠。`.vela` 的 treeStyle: "mindmap" 使用横向树布局，默认 indent 为缩进列表。

关系图支持独立添加节点、拖动、平移、滚轮与双指缩放、适应全图；从节点边缘的 ＋ 拖到另一节点建立关系。点击关系线可修改标签、线型或删除。拖动只改变被拖节点的坐标，其余节点首次拖动前冻结默认坐标；保存、重开不会挤动其他节点。“一键整理”按关系连通分组与距离层级重新布局，循环关系也可处理，不改变关系、正文锚点或剧情树层级。剧情树的整理使用层级布局。

点击节点打开详情：宽屏右侧栏，窄屏底部弹层。标题、概要、Markdown 详情、状态、标签与颜色可编辑，点击“保存节点”写入文件。未提交的详情输入作为本机草稿保存，切换文件或重启后可恢复；不会覆盖外部更新后的不同节点。删除节点及子节点需要再次确认，关联关系边同步删除。未知字段在编辑、序列化和合并时保留。

## 正文链接

在 TXT / Markdown / LaTeX 中选择文字，打开选区菜单“更多 → 链接到大纲节点…”，选择文件和节点。无选区时可从命令面板调用同一命令，使用光标所在行的段落。正文保持原样，锚点只在大纲文件内；行侧小标记可显示所属节点并返回大纲。

长按节点（默认 500 ms）、双击，或右键菜单“跳转到正文”，跳到第一个锚点；多个锚点显示选择列表。手指移动超过 8 px 取消长按。跳转核对 quote 与 prefix，选中准确的 UTF-16 偏移范围，闪烁约 1 秒。无法唯一定位时进入“待确认锚点”，不会猜测另一个同文段落。

**按本次开发中的用户更新要求，正文编辑时直接改写大纲中的锚点偏移，与正文一起自动保存。** 不再等手动保存大纲，也不另存锚点恢复草稿。正文与大纲同属工作区的保存状态和本地历史；若保存失败，两者均保留未保存状态和恢复信息。当前实现读取已载入以及启动时发现的大纲，后续文件操作也会先载入尚未读取的规划文件，防止遗漏引用。

移动、重命名时改写 anchors[].path（工作区根目录相对路径）；删除目标保留路径并标记 invalid / needsReview，便于修复。非法大纲保留原文，可以切换 CodeMirror JSON 源码编辑。切换文件时如内容已被锚点改写，不复用旧的编辑器文本。

## 设置与同步

`formats.outline` 支持 defaultView（tree / graph）、treeStyle（indent / mindmap）、longPressMs（200–2000）、statuses（最多 64 个稳定 ID、中文标签、颜色）、showEditorMarkers。全局 → 作品 → files[path] 继承；数组整体覆盖。状态值未知时仍保留并显示，避免其他设备的状态配置损坏现有节点。

结构化三方合并按节点键和关系、锚点 ID 合并，独立字段修改可组合；父子顺序冲突、删除与修改冲突或合并后结构无效时回退原有文本合并，供用户逐项确认。

建议增强中的字数汇总、状态 / 标签筛选、Markdown / OPML 导出和阅读页旁标题未包含在本次基础功能中。
