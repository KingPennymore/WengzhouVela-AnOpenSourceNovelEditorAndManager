# 大纲与关系

`.process` / `.pcs` 是 version: 1 的 JSON，kind 为 OUTLINE，最多 4 MiB。一个文件维护两套独立数据：顶层 `nodes` / `edges` 是“大纲”，`relations.nodes` / `relations.edges` 是“关系”。切换视图不会复制或共享节点、详情、坐标、锚点和连线；节点 ID 只在各自集合内唯一。

```json
{
  "version": 1,
  "name": "第一卷",
  "view": "outline",
  "root": "",
  "roots": [],
  "nodes": {},
  "edges": [],
  "relations": { "nodes": {}, "edges": [] }
}
```

两套数据合计最多 5000 个节点、10000 条连线。新文件完全空白，允许多个顶层节点。旧文件的顶层节点、children 和 edges 全部保留在“大纲”中，不自动迁入“关系”；旧 tree / graph 视图值兼容为大纲，首次实际保存时记录新的视图值。未知字段保留，JSON 固定键顺序、2 空格缩进、末尾换行。

## 大纲

大纲采用画布上的有向图，不再提供缩进树列表。children 保存无循环、单父节点的情节层级，画布展示父子箭头与额外的有向 edges。从节点的 ＋ 拖到另一个节点可添加有向连线；点击额外连线编辑标签、方向、Markdown 描述、线型或删除。父子连线也可编辑，信息保存在子节点 parentEdge；删除父子连线将子节点移回顶层，保留节点内容。

底栏可添加节点、新建子节点、一键整理和适应全图。选中节点后，即使关闭详情仍可新建子节点；新节点会进入视口并打开详情。Enter 新建同级节点，Ctrl / Command + Enter 新建子节点，Tab 缩进，Shift+Tab 反缩进。详情中的父节点选择器也可调整层级，排除自身及后代，防止循环；顶层选项取消父节点。父节点旁可折叠或展开后代。

拖动只改变被拖节点的坐标，添加节点时冻结其他节点的位置，保存和重新打开保持坐标。“一键整理”按情节层级重新布局，不修改正文锚点与连线。

## 关系

关系没有父子层级，不允许自身连接或同一对节点重复连接。添加角色或其他对象后，从 ＋ 拖到目标节点建立关系；反方向重复拖动不会新增重复边。按本次反馈，连线支持无方向、起点到终点、终点到起点和双向，保存为 direction: none / forward / backward / both；新建默认 forward，旧关系未设置时继续无方向。点击连线可编辑短标签、线型、方向与 Markdown 描述 description，或删除。节点连接数和整理仍按忽略方向后的唯一邻居计算。

节点尺寸按唯一直接相邻节点数（图论中的度）变化，不枚举无限环路或全部通路。圆形节点直径上限 196 px；删除连线或节点后重新计算，孤立节点仍可点击查看详情。一键整理按连通组排成同心环，支持循环关系，只调整关系集合。

标签栏类型标识使用 PCS，一键整理采用独立的四节点排列图标。详情使用固定不滚动的背景外层与透明滚动内容，滚动到底部也保持完整背景。已移除节点双击跳转监听，按钮使用 touch-action: manipulation 避免浏览器双击缩放等待。

两种画布都支持拖动、平移、滚轮、双指缩放与适应全图。选中的节点、缩放和平移在各视图分别维护。常用动作放在文舟原有底部操作区，撤销 / 重做使用原有一组按钮；顶部保持单行，溢出工具进入右上角纵向“更多操作”。插件可以调整局部顶栏、底栏和侧栏。

## 详情与正文链接

点击节点打开详情：宽屏右侧栏，窄屏底部弹层。标题、概要、Markdown 详情、状态、标签、颜色与锚点可编辑。未提交的详情输入作为按文件、集合、节点区分的本机草稿保存；切换文件或重启后恢复，已有外部修改时不覆盖。大纲删除节点及后代，关系只删除本节点与相关连线，均需再次确认。

在 TXT / Markdown / LaTeX 中选择文字，打开选区菜单“更多 → 链接到大纲节点…”，可选择大纲中的剧情节点。无选区时从命令面板调用同一命令，使用光标所在行。正文内容不变，锚点保存在对应节点中；行侧小标记返回正确的文件、集合和节点。

长按（默认 500 ms）或右键“跳转到正文”打开锚点；多个锚点显示选择列表。移动超过 8 px 取消长按。跳转用 quote 与 prefix 核对 UTF-16 偏移，选中范围并闪烁约 1 秒。不唯一时标记 needsReview，在“更多操作 → 待确认锚点”中查看。

关系节点现在从详情中选择术语库和词条，记录 glossaryLinks: [{id, path, entryId, label}]，通过稳定词条 ID 定位；术语改名后仍能跳转，多个链接先弹出选择。缺少词条 ID 的旧术语库仅在确认建立链接时补全 ID，检查目标原文未变化后保存。术语库路径移动、删除与链接三方合并同样支持。旧关系中的正文锚点保留在“旧正文锚点”，不自动删除或转换成不可靠的词条匹配。

**正文编辑时仍直接改写大纲和旧关系中的正文锚点偏移，与正文一起自动保存。** 保存失败保留未保存状态与恢复信息。移动、重命名改写 anchors[].path；删除目标保留路径并标记 invalid / needsReview。非法文件保留原文，可切换 CodeMirror JSON 源码修复。

## 设置与同步

`formats.outline.defaultView` 为 outline 或 relations；旧 tree / graph 和 treeStyle 字段兼容读取，但不再切换到树列表。longPressMs（200–2000）、statuses（最多 64 项）、showEditorMarkers 保留。配置按全局 → 作品 → files[path] 继承。

两套集合均按节点键、关系 ID 和锚点 ID 进行结构化三方合并。独立字段修改可组合；父子顺序、删除与修改冲突或合并后无效时回退文本合并。

字数汇总、状态 / 标签筛选、Markdown / OPML 导出和阅读页旁标题仍为后续增强。接口见 [PLANNING-PLUGINS.md](PLANNING-PLUGINS.md)。

## 关系画布的视觉与整理

大纲使用有层级的矩形情节卡片与横向连线；关系使用圆形人物节点、名字首字标识、连接数及弧线，颜色跟随文舟外观。关系节点直径为 `112 × (1 + min(0.75, sqrt(连接数) × 0.16))`，只计算不同的相邻对象。

关系的一键整理以每个连通组中连接最多的节点为中心，将其他节点排在同心环上；多个连通组分别排列。新节点没有坐标时使用这个布局，已有坐标保持原样；拖动一个节点不会改变其他节点，只有主动整理才改写全组坐标。两种视图的详情、方向、描述、术语库链接和独立数据不变。

## 卡片内容

大纲情节卡片直接显示标题、概要和 Markdown 详情的文本预览，区域以细线分隔。标题最多 2 行、概要最多 3 行、详情最多 6 行，长文在详情面板完整编辑与阅读，文件内容不裁剪。一键整理根据卡片高度留出间距；已有坐标保留，避免更新显示方式时移动用户的节点。关系画布继续使用圆形人物节点，与情节卡片区分。
