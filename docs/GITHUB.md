# GitHub 同步与订阅

令牌登录为默认入口。细粒度令牌需要 Metadata 读取与目标仓库 Contents 读写权限；仓库管理另需管理权限。仓库返回只读权限或已归档时，界面禁用提交、删除、创建分支等写操作；最终权限仍由 GitHub 校验。令牌保存在各平台安全存储，不写入文稿、源码或日志；退出不删除文稿。

原生启动断网时可显示上次账号的仓库摘要缓存（最多 500 项），明确标为离线并禁用写入；刷新恢复连接，缓存不包含令牌，退出删除账号列表缓存。

## 拉取

完整仓库或长按多选文件/文件夹从同一不可变提交下载。选中文件夹包括后代，相对路径保持。下载完成显示新增、相同、远端更新、本地修改四类状态，然后选择写入。相同项默认不重复写入，冲突默认不勾选；可以展开对照，确认覆盖前保留本地历史。预览后本地文本变化会拒绝覆盖。

原生批量写入使用事务；下载期间取消不修改文件，写入出错回滚。保留本地独有文件，不因远端缺失而自动删除，不自动打开拉取的文稿。保留的冲突记在关联中，全部处理后才能提交，避免把未合并文件推回远端。

每文件最大 8 MB、一次最大 64 MB、目录树最大 5000 项；不完整目录逐级读取，仍超限或包含未选可忽略范围以外的子模块时明确失败。不执行下载的代码、Git hooks 或 Git LFS；这不是完整 Git 客户端，没有 rebase、cherry-pick 或本地分支合并。

## 提交

单文稿提交使用已关联 SHA，冲突不会自动抓取新 SHA 后强行覆盖。工作区提交展示新增、修改、未变和已删除的已跟踪文件，可多选；删除远端文件默认不勾选，需显式确认。重命名表现为新增新路径并删除旧路径。个人 `.global.vela`、私有历史/缓存、证书和凭据文件默认排除。

工作区关联保存仓库、分支、目标前缀、基线提交与每文件摘要。提交前检查远端分支基线和本地预览是否变化，分支更新使用非强制原子操作；并发远端提交不会被强推覆盖。首次关联没有基线时，对所选文件建立提交。私有元数据不作为提交文件。

只对 GET 的网络/服务端错误有限重试，写请求不自动重放。401 提示重新登录；403 提示权限、组织授权或限流；404 可能表示无权访问；409 提示重新读取并对照。移动平台桥接中的在途网络请求不能全部立即中断，但取消后不进入落盘。

## 订阅

订阅 HTTPS 仓库地址只保存元数据，询问是否立即拉取，不创建空文稿。进入应用/订阅页会尝试刷新；可筛选全部、未读、已下载、刷新失败，取消刷新或批量删除/忽略。删除订阅保留本地下载。刷新失败保留上次内容和未读状态，查看或忽略记录时间。

`.vela` 仓库只监视阅读清单内容；配置自身更新不产生未读点。未修改的本地配置静默更新，用户修改过的配置保留并标记冲突。拉取阅读清单还包含配置及可静态解析的图片、CSS、ES 模块、Markdown 链接、TeX 子文件/图片/参考文献；动态生成或不常见依赖可能需要完整拉取，依赖仍保持原相对路径。

已拉取正文可离线阅读。再次读取远端更新时保护本地修改；不可变 blob 缓存有数量/容量上限。发布版本与 Changelog 显示经过安全 Markdown 渲染；订阅不会运行仓库代码。
