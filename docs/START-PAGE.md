# 启动页界面更新（0.9.5）

## 界面与交互

- 启动页保留文件侧栏、写作、Git、订阅、阅读和更多操作的主导航。
- 启动页隐藏编辑器专用的文件标签行、显示模式按钮、章节目录按钮、快捷操作底栏和状态栏，内容区直接延伸至底部安全区；进入文稿后恢复编辑界面。
- 所有启动页入口每行一个，左侧图标、右侧标题和简短说明。新建、导入、最近文件、Git 仓库、操作指南、命令与快捷键、插件与组件、设置均使用同一组主题颜色、边框、圆角、尺寸和交互反馈。
- 最近文件收进独立按钮。点击后按钮区向左滑出、最近文件从右侧滑入；返回时方向相反。文件列表保留原有的更新时间排序和文件类型、路径信息。
- 可用返回按钮、Esc 或 Android / HarmonyOS 的宿主返回操作回到入口区。点击最近文件仍按原流程打开文稿。再次进入启动页默认显示入口区。
- 非活动面板不接受点击、键盘焦点或屏幕阅读器访问；切换后焦点移到返回按钮，返回时恢复至最近文件按钮。系统选择减少动态效果时即时切换。
- 入口区与文件列表独立滚动，小屏及横屏下均可访问底部入口。主导航不随内容滚动。

## 源码位置

- `web/start-page.mjs`：独立启动页结构和面板切换。
- `web/app.js`：启动页、编辑器状态与系统返回操作衔接。
- `web/design.css`：统一按钮样式、内容区布局与滑动动画。
- `web/sidebars.mjs`：启动页不预留编辑底栏高度。
- `web/icons.mjs`、`web/i18n.mjs`：最近文件图标和新增中英文说明。
- `tests/start-page-browser.mjs`：布局、颜色、焦点、返回、打开文稿与保存的浏览器回归检查。
- `tests/start-page-helper.mjs`：原有浏览器测试通过“最近文件”入口打开文稿。

## 验证与构建

- `npm test`：200 项现有逻辑测试通过。
- `npm run build:lite`：轻量版共享前端构建通过，更新了源码包中的 HarmonyOS 预构建资源。
- `node scripts/check-build.mjs`：三端版本、前端摘要和组件资源清单检查通过。
- 修改后的 JavaScript 文件语法检查通过。
- 当前执行环境没有浏览器可执行文件；浏览器下载未成功，`npm run test:start` 与浏览器验证因此未执行成功。不能将上述逻辑与构建检查视为动画、布局或真机验证。
- 可在安装好 Playwright Chromium 的开发环境运行 `npm run test:start`。测试覆盖 Android、HarmonyOS、Windows 三种界面配置，320–1366px 宽度、浅色/深色、中英文、横屏及减少动态效果；结果和截图写入 `test-results/start-page/`。
- 本次交付为源码及共享前端资源，未编译新的 APK、HAP 或 Windows 安装包。

本次更新基于包含 ODF 独立组件与电子书 PDF 阅读组件的已上传源码，保留这些组件及现有功能。
