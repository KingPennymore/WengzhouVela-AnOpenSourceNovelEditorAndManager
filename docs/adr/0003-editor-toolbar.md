# ADR 0003：编辑顶栏的窄屏切换

状态：已采纳。日期：2026-10-24。

## 背景

窄屏编辑时需要让常用文稿操作直接可见，同时继续沿用原有顶栏的按钮、图标与配色。宽屏空间充足，保留完整导航。

## 决定

- 以现有布局的 900 CSS 像素为分界。宽屏编辑时导航完整、编辑按钮维持原尺寸，查找与替换、选中词加入术语库、导出小说文件固定显示在目录按钮左侧。
- 窄屏进入编辑页时放大编辑按钮，收起仓库、订阅、阅读入口，显示三项文稿操作。再次点击当前编辑入口时切换导航与文稿操作的位置。
- 顶栏状态由独立的 `EditorChrome` 管理。正文输入、选择、文档预览、更多菜单开合与布局刷新不重置用户的选择；离开并重新进入编辑页时恢复窄屏编辑布局。
- 窗口缩放只改变呈现方式，保留窄屏选择。宽屏点击编辑入口不切换该选择。
- 在顶栏与更多菜单之间移动同一批按钮，保留现有事件、禁用状态和无障碍标签，避免复制按钮导致操作分叉。

## 验证

浏览器回归覆盖 320、390、1280 像素下的明暗主题、导航切换、正文输入、更多菜单及窗口缩放；断言按钮顺序、唯一性、可达性和状态保持。
