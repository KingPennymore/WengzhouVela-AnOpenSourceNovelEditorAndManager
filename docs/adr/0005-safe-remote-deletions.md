# 0005：以完整快照和本地版本保护同步删除

状态：已采用。

## 背景

仅更新拉取结果会留下远端已删除或重命名的旧文件，但直接按远端列表清理本地目录会误删本地文稿和未选中的文件。
部分文稿关联还未纳入分支维度，可能使不同分支共用本地内容。

## 决定

由适配器返回完整快照标志、选择范围和完整路径清单。只有完整且未过滤的仓库拉取可以产生删除候选，
候选还必须属于上次跟踪的同一平台、实例、仓库、分支和本地目录。目录前缀映射不明确时不推断删除。

删除项默认不选，正文有修改或附件无法通过版本校验时保留。应用前重新核对正文和磁盘字节，
与拉取写入一起交给原生存储层处理，使用已有回收站及异常回滚。禁止以永久删除作为同步清理手段。

保留远端删除文件不等于决定重新上传，提交预览对此单独标记且不默认勾选。
不同分支使用独立本地关联和目录，目标归属冲突时拒绝写入。
状态文案说明上次同步基线，不声称已实时确认远端最新内容。

## 结果

远端删除可以在可审阅、可恢复的前提下清理。局部拉取、本地独有内容和未确认的修改不会被删除。
空目录继续保留。移动端存储层需要维护与 Windows 相同的版本和回收站约束，
HarmonyOS 的进程中断原子性仍受原有暂存机制限制，后续应补持久事务恢复和真机验证。
