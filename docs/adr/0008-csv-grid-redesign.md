# 0008：CSV 表格改为画布网格与局部源码改动

状态：已采用。取代 [ADR 0007](0007-linked-csv-tables.md) 中关于分页渲染、同时挂载 2,000 个单元格和整表重写的部分；TXT 关联表格、路径限制与“只读取源文件快照”的决定继续有效。

## 背景

旧表格把每个单元格渲染为 `<textarea>`，每页最多 2,000 个，用上一页 / 下一页和左侧列 / 右侧列翻页。列宽固定 144 px，表头永远是 A/B/C，行列操作要进对话框填写行列号。

更严重的是数据层：一次单元格编辑会重新序列化并整篇替换 CodeMirror 文档。`a,"b"\r\nc,d\r\n` 编辑后会变成 `a,b\nc,d`，多余引号、CRLF 和末尾换行丢失，Git 同步因此经常显示整文件改动。按键开销与文件大小成正比；一处引号错误就让整张表只剩一句报错。

阅读页复用分页后，看到的是同一个有界编辑器而不是可滚动的表格；手机点格子立即弹键盘，“只看”和“要编辑”分不开，也没有区域选择、复制和删除。

## 决定

- **解析器记录源码位置。** `csv-model.mjs` 为每个格子保存 `{from, to, quoted}`，同时识别分隔符、换行符、`sep=` 行、BOM、末尾换行和列数一致性。所有编辑输出 CodeMirror 局部改动：改单格只替换该字段；插删行只改那几行；插删移列、排序和区域粘贴合并为一次事务。改动必须经过原文稿的撤销和保存流程（`ports.change`），表格不保存第二份数据。
- **虚拟画布网格。** `csv-grid.mjs` 只渲染可见行列和缓冲区，表头、行号与单元格位于同一个缩放画布，整张表一起平移缩放。横向平移到行号列离开视口时，左侧显示一条不参与横向滚动的行号提示，避免丢失行定位。行高按 1 / 2 / 3 行文字预先计算，列宽按前 80 行估算并可拖动。视口状态 `{x, y, scale}` 保存在本机视图状态，不写进 CSV。
- **平移与缩放有边界。** 缩放范围 25%–300%；低于 50% 时用 canvas 概览绘制整表，只保留行号列名和内容色块；右下角小地图跳转。平移被限制为：表格小于视口时完整留在视口内，大于视口时始终覆盖视口，不能把内容拖到全部不可见。手势期间先对画布做 CSS transform，结束后按真实布局尺寸重绘，保证文字清晰。缩放和滚动位置按文稿记忆，首次打开按宽度决定 100% 或适应宽度。
- **先选中再编辑。** 整张表只有一个浮层编辑框；双击、Enter、F2 或直接打字进入，手机上改用底部编辑栏。区域选择、角手柄、TSV 复制粘贴、右键 / 长按菜单、查找与筛选都在 `csv-grid-editor.mjs` 中。排序分为“只改变显示顺序”和“写入文件”。
- **阅读页不复用画布。** 阅读页使用同一组件的 `readOnly` 模式：原生滚动、只渲染可见区域、不可编辑，也没有缩放画布。它保留既有的 `.csv-panel` 滑动排除规则，并按 `csvScrollTop` / `csvScrollLeft` 恢复位置。
- **TXT 内嵌表格保持静态。** `csvTableMarkup` / `mountCsvTable` 仍输出最多 100 行 × 20 列的转义静态 HTML，不做缩放，避免把交互式网格塞进正文排版和分页测量。表格宽度限制在正文栏宽内，高度随行数增长，字号独立于正文字号，按可用宽度和列数在 8–16 px 之间自适应；表格不建立自己的上下滚动区域，滑动仍交给正文页面。
- **复用规划视图的外观。** 顶栏、更多菜单、底栏、按钮尺寸和“更多操作”溢出行为沿用 `.planning-*` 结构与图标；PCS 大纲的 `bindPlane` 行为不变，只是新增 `wheel: 'zoom' | 'pan'` 选项供表格选择。

## 结果

- 编辑一个格子只改动该格子的字节，未改动的引号、CRLF、BOM、`sep=` 和末尾换行原样保留，Git 差异只包含实际修改。
- DOM 节点数与文件大小无关；8 MB / 200,000 单元格上限内，滚动不再是翻页状态机。
- 手机点选不再弹出键盘；区域选择、复制、粘贴、查找、排序和移动行列都可从画布完成。
- 大数据表在低缩放下先显示概览，点击后放大；阅读页始终是可滚动的只读表格。
- 不引入公式或电子表格引擎。仍然只支持最多 8 MB、200,000 个单元格；列宽、缩放、滚动位置和排序显示顺序是本机视图状态，不写进 CSV，也不参与同步。
- Windows、鸿蒙和安卓的原生导入、扫描、保存与冲突比较按 CSV/TSV 扩展名保留 BOM，与 Web 导入及远端同步使用同一文本表示；其他文本格式沿用原有解码规则。末尾单字段空记录必要时使用显式空引号，保持记录数量与末尾换行状态。
- 测试入口：`tests/csv-tables.test.mjs`（模型、局部改动、格式保留、可见范围）、`tests/csv-tables-browser.mjs`（三档宽度的编辑器交互）、`tests/studio-browser.mjs`（阅读页只读网格）以及既有 features / workspace 回归。
