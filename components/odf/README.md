# ODF 文档组件 1.0.0

在本修订的 Vela 0.9.5 中，通过“更多 → 插件与组件 → 从 ZIP 安装”导入 `Vela-ODF-1.0.0.zip`。适用于三端共用前端；旧版宿主没有 `document-formats-v1` 能力，会拒绝加载，请先更新宿主。

- ODT/OTT、VODT/.velaodt、FODT：普通文字、标题、常用字体属性、继承样式、列表、表格、位图预览。
- 自建 VODT：常用富文本编辑、图片插入/缩放/删除、有序/无序列表、表格、颜色、字号、行距、上下标。
- 导入 ODT：编辑可安全转换的普通段落，保留周围 XML、页眉页脚、脚注、书签、字段、修订和所有包附件。包含特殊内容的段落只读。结构编辑请创建明确标注的简化副本。
- ODS/OTS/FODS：基础表格预览、合并单元格、重复行/列限量展开、显示公式的缓存结果，不计算公式。
- ODP/OTP/FODP、ODG/OTG/FODG：文字、页面分组、位图基础预览，不实现精确坐标排版、图形绘制、动画。
- 导出原格式包、Flat ODF、TXT、VODT。存在复杂包附件时禁止标准 Flat ODF 的有损导出，可导出原格式包或 VODT。

停止或卸载组件不会删除任何文稿；未安装时，现有 Flat ODF/VODT 仍可查看纯文本和源码，二进制 ODF 导入会提示安装。原始二进制文件保留在用户选择来源中，导入生成 `.vodt` 工作副本，`vela:package` 保留原包所有条目。未修改导出保留每个条目的原始字节（ZIP 压缩容器会重建，不保证整包字节相同）；修改后保留附件字节、清单及不修改的 XML 内容。宏/脚本保留为不执行的数据。

限制：输入包/工作文稿 8 MiB；解压 32 MiB / 2048 条目；单张显示图片 2 MiB；XML 深度 80 / 100000 元素；预览最多 30000 节点，重复行/列各最多显示 200。包含原包的 VODT 会增加工作副本空间，超过 8 MiB 时拒绝导入而非截断。加密文件拒绝；带数字签名的包只读，未经修改可导出，不校验真实性。缺失/不支持的图片显示占位并保留引用。ODF 1.2/1.3 的常见结构为主要兼容目标，保留输入版本号；不宣称 ODF 全标准一致性或与 LibreOffice/Word 像素一致。

详细支持矩阵、包保留实现、开发协议和验证见 `docs/ODF-COMPONENT.md`。本组件独立打包，主程序不打入渲染/图片/转换引擎，没有新增大型办公套件或 WASM 运行时。
