# 电子书制作 0.2.0

在“插件与组件 → 从 ZIP 安装”安装 `Vela-Ebook-Studio-0.2.0.zip`。需要支持 `document-formats-v2` 的宿主（宿主提交 c27a111 起）；最新宿主会把可视化正文的快捷键交给编辑器处理。

导入 EPUB，或点击工作区中已有的 EPUB，生成独立 `.vepub` 编辑源。也可以运行命令“电子书制作：新建书籍”或“电子书制作：从当前文稿创建”。原书不会被覆盖。编辑源保存章节、CSS、图片、字体及其他原始资源，宿主对编辑源的上限为 8 MiB；原书文件最大 32 MiB、展开最大 32 MiB / 2048 个资源，因此包含大量图片的书籍可能因编辑源大小被拒绝。

支持 Tiptap 可视化正文与 XHTML 源码切换，正文/标题、粗体、斜体、下划线、列表、引用和本章节撤销/重做；书籍信息、CSS 编辑，章节新增、改名、排序和从阅读顺序移除；中文小说、紧凑阅读和纸书模板；隔离的章节预览及 Paged.js 当前章节分页预览；EPUB 与传统 MOBI 导出。移除章节保留其原始资源，避免损坏交叉引用。未修改的图片、字体及其他文件在 EPUB 中保持字节一致。导出时更新元数据、阅读顺序；调整目录后重新生成平级目录，不保留原目录的嵌套层级。MOBI 使用传统 v6 格式，只支持其能够表达的正文与 PNG/JPEG/GIF 插图，复杂样式、SVG、音视频和现代排版会简化。

可视化区域显示基础格式，原书 CSS、排版模板及最终版面在预览中查看。原有属性、脚注锚点、链接和插图路径保存在文档模型中，不把任意书籍 HTML/CSS 放进宿主页面。暂不支持直接编辑的表格、注音、SVG 等以保护块呈现，内部原始 XML 保留，可切换源码修改；选中保护块后删除会将该内容移除。已有图片可显示与选中，首版未提供图片上传、裁剪或缩放工具。模式或章节切换会重建当前编辑器，局部撤销历史不跨越这些操作；保存内容不受影响。未完成的源码草稿自动退回源码模式，修正后才能进入可视化或导出。

手机宽度下采用单栏，格式工具栏横向滚动，常用触控按钮至少 40 px 高，预览默认收起，点击“显示预览”展开；分页预览会自动展开。移动端输入框使用至少 16 px 字号。中文组合输入期间不重建编辑器或自动更新预览；视口缩小后仍可滚动正文与操作工具。浏览器模拟验证不能替代 Android/HarmonyOS 实机软键盘验收。

首版不支持加密/DRM、字体混淆、SVG 固定版面正文、AZW3/KF8、AZW4、KFX；不包含移除 DRM 的功能。分页预览只处理当前章节，属于当前设备的版面预览，EPUB 阅读器会根据自己的设置重新排版。尚未做实体 Kindle 验收。

直接复用：

- `@tiptap/core`、`@tiptap/pm`、`@tiptap/starter-kit` 3.32.0（MIT）：本地可视化输入、常用格式及撤销/重做，随插件打包，不依赖 CDN、账号或商业扩展。
- `epub-gen-memory` 1.1.2（MIT）：新书的 EPUB 生成。
- `Paged.js` 0.4.3（MIT）：分页版面预览，按需加载，布局发生在禁用书籍脚本的隔离框架中。
- `fflate`（MIT）：读取、保留及重新打包 EPUB 资源。
- `iepub` 1.3.7（MIT）：MOBI 写入，编译为不依赖服务器或原生可执行程序的 WASM。原始源码、许可、来源校验和改动记录在 `vendor/iepub`；保留 MOBI 写入实现，裁剪未使用的 EPUB/ZIP/CSS 依赖并适配 WASM 时间戳。

插件附带 `THIRD_PARTY_NOTICES.json` 和 `licenses/`，记录直接及间接依赖的许可。主项目为 MIT 不代表所有间接依赖也都是 MIT；安装包保留它们各自的许可声明。

构建：根目录 `npm ci`，运行 `npm run package:ebook-studio`。验证运行 `npm run test:ebook-studio`（导入导出回归与可视化/移动布局两组浏览器脚本）。普通打包使用随源码保存的 WASM；重建 WASM 需 Rust 和 `wasm32-unknown-unknown` 目标，运行 `npm run build:ebook-mobi`。Rust 依赖由 Cargo.lock 固定。插件单独打包，宿主启动时不加载这些库。

适配说明：epub-gen-memory 的原始 EJS 模板在打包时预编译，运行时不调用动态代码求值。Paged.js 的可信代码由宿主加载，绑定到允许同源访问但禁止脚本执行的预览框架；书籍本身不能执行脚本。预览资源使用本地 data URL，禁止远端请求。未完成的 XHTML 编辑以草稿形式保存，修正后才写入章节并导出。
