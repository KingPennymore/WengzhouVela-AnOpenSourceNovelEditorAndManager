# 电子书阅读组件 1.0.0

在“更多 → 插件与组件 → 从 ZIP 安装”导入 `Vela-Ebook-Reader-1.0.0.zip`，点击组件卡片的“打开阅读器”，或在命令菜单选择“电子书：打开阅读器”。三端共享同一插件包。

支持离线阅读 EPUB 2/3 的 HTML 正文、FB2 与仅含一本 FB2 的 `.fb2.zip`、TXT（UTF-8、UTF-16、GB18030）、HTML、无 DRM 的传统 MOBI/AZW（MOBI7，未压缩或 PalmDOC）。提供阅读顺序、章节切换、PNG/JPEG/GIF/WebP 插图、字号、夜间和最近 100 本书的章节进度。

导入使用宿主的文件选择器；书籍存入当前 .vela 工作区，没有工作区时创建“电子书”工作区，重名自动改名。再次打开可从“工作区书籍”选取。插件停用/卸载清理页面和命令，保留用户导入的书籍；卸载插件会清除插件设置。进度精度为章节，不保存滚动偏移。

单书 32 MiB，ZIP 展开 64 MiB / 2048 文件，单章正文 8 MiB；单图片最多 4 MiB。不能绕过设备存储或项目配额。原书仍然保留，解析失败不会修改书籍。

本组件按基础流式排版显示正文；不导入出版社 CSS、字体、脚本、音视频、SVG 插图或固定版面排版。EPUB 字体混淆允许保留，但不使用内嵌字体；正文加密/DRM 拒绝打开。MOBI 双格式文件仅阅读旧版 MOBI7 部分；KF8/AZW3/KFX、HUFF/CDIC、MOBI filepos 导航暂不支持，建议转换为无 DRM EPUB。`.azw3` 扩展名会检测文件头并明确报告 KF8 不支持，不宣称完整 AZW3 支持。PDF 使用主应用现有阅读器。

构建：根目录 `npm ci`，然后 `npm run package:ebook`；`npm run build` 也会生成组件。组件不打入主程序前端，安装才加载。源码见 `engine.mjs`、`main.mjs`；开发协议见 `docs/COMPONENTS.md`。
